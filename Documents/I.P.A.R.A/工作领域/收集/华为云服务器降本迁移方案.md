## 一、结论：3 年省 ¥11,898（年省 ¥3,966，−80%）

**定稿方案：华东-上海一 ECS `x2e.2u.4g` 2核4GiB + 系统盘 80GB，包 3 年 ¥3,033.55，不买云数据库。**

> ✅ 已向客服确认两条：①「只要服务器、不要云数据库」活动价算数；②「系统盘 40GB→80GB」报价 ¥3,033.55，活动折扣保留。

| 方案 | 含 RDS | 锁定 | 年化 | 3年总额 |
|---|---|---|---|---|
| 原样续费 | 是 | 1年 | ¥4,977.20 | ¥14,931.60 |
| 新购 Flexus X（北京四） | 否 | 1年 | ¥2,389.04 | ¥7,167.12 |
| 客服报价·乌兰察布一（ECS+RDS） | 是 | 3年 | ¥2,093.92 | ¥6,281.77 |
| 客服报价·上海一（ECS 40G） | 否 | 3年 | ¥948.18 | ¥2,844.55 |
| **客服报价·上海一（ECS 80G）** ⭐ | 否 | 3年 | **¥1,011.18** | **¥3,033.55** |

### 为什么加钱上 80G

| 配置 | 3年总价 | 年化 | 每GB成本 |
|---|---|---|---|
| 40GB | ¥2,844.55 | ¥948.18 | — |
| **80GB** | **¥3,033.55** | **¥1,011.18** | 增量 ¥0.13/GB/月 |
| 差额 | **+¥189.00** | +¥63/年 | 远低于标准价 ¥0.35/GB/月 |

多 40GB 每月只多 ¥5.25，且**直接绕开「这台促销机器可能不能在线扩容」的风险** —— 一次买够，三年不操心。

**80G 容量测算**：系统+宝塔+MySQL8+PHP8+venv 约 5–8G，5 个站点 3.5G，数据库约 0.5G → 起步约 30G，余量约 50G。`shop-panel` 上传目录累积 2 年才 1.1G，50G 撑 3 年绰绰有余。

省钱来自两处：

1. **不买云数据库 RDS** —— 三个库合计只有 **15MB**，合并回本机 MySQL，省 ¥3,175.20 / 3 年
2. **上海一折扣比乌兰察布深** —— 同配置上海 5.1 折 vs 乌兰察布 6.7 折

### 华为云客服报价：两地比选（2026-08-19）

两份报价**配置完全一致** —— `X86 通用计算增强型 x2e.2u.4g` 2核4GiB · AlmaLinux 9.4 64bit · 高IO 40GB · 全动态BGP 独享 · 按带宽计费 5Mbit/s · 包 3 年：

| 区域 | ECS 原价 | ECS 活动价 | 折扣 | 年化 |
|---|---|---|---|---|
| 华北-乌兰察布一 | ¥4,988.92 | ¥3,359.29 | 6.7 折 | ¥1,119.76 |
| **华东-上海一** ⭐ | ¥5,568.24 | **¥2,844.55** | **5.1 折** | **¥948.18** |

同期报的云数据库（**决定不买**）：乌兰察布一 MySQL 8.0 单机 2核4G+SSD 40GB 活动价 ¥2,922.48；上海一同规格 ¥3,175.20。

> ⚠️ **清单总价含数据库，别看错**：上海一清单总价 ¥6,019.75 = 服务器 ¥2,844.55 + 云数据库 ¥3,175.20。只买服务器实付 **¥2,844.55**。

**选上海一而非乌兰察布的理由**：便宜 ¥514.74；上海是网络枢纽，出口质量优于内蒙古偏远区；区域成熟度更高。北京到上海约 30ms、到乌兰察布约 20ms，10ms 差异对网站无感。

**交叉验证**：在 ECS 自定义购买页实测 `x2e.2u.4g`（乌兰察布一）基准价 **¥102.60/月**，纯实例 3 年即 ¥3,693.60 —— 客服报价还含 40G 盘与 5M EIP，确认是真折扣。

**客服选得比原方案好的两点**：

- **AlmaLinux 9.4** 优于原建议的 Ubuntu 22.04 —— RHEL 系，与现有 CentOS 8 同源，宝塔迁移 / PHP 编译 / systemd 配置更平滑
- **3 年包** 折扣深度远超 1 年包

## 五、迁移时间线（距 09/15 仅 27 天）

```
08/19-08/21  ① 备案授权码换绑申请        ← 最长路径，先启动
             ② 买新机（Flexus X，Ubuntu 22.04）
08/22-08/26  ③ RDS 三个库 dump → 新机本地 MySQL
             ④ 装宝塔，一键迁移 5 个 PHP 站点
             ⑤ django-jin 手工搬：venv 重建 + systemd
08/27-09/06  ⑥ 双机并行，用 hosts 指向新机验证
09/07-09/10  ⑦ DNS 切换（提前把 TTL 调到 60s）
```

## 七、顺带要修的问题

| 问题 | 处置 |
|---|---|
| Django 用 `manage.py runserver` 跑生产 | 新机换 **gunicorn**（`gunicorn_conf.py` 现成的），别把开发服务器带过去 |
| 本机 MySQL 监听所有网卡 | 新机绑 `127.0.0.1` |
| 防火墙放行了 21 个端口，多数背后无服务 | 新机只开 22/80/443，按需再加 |
| `frps` 内网穿透服务在跑但 0 客户端 | 不迁 |
| `:6000` 反代到一个不存在的 Flask 应用 | 不迁 |
| 2 张 SSL 证书 2024 年就过期 | 新机用 Let's Encrypt 重签，过期的不要 |
| root 密码登录 + 安全 agent 会封禁高频登录 | 新机**只用密钥对**，禁用密码登录 |
| **MySQL 版本认证坑** | 旧机本地 MySQL 客户端是 **5.7**，ShopXO/ThinkPHP 老版本在 **MySQL 8** 默认 `caching_sha2_password` 下会连不上 —— 新机装 MySQL 8 需改认证插件为 `mysql_native_password`，或直接装 5.7 |
