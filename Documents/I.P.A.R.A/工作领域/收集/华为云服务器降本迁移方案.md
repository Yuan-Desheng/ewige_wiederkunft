> 生产服务器 `hecs-295241`（华北-北京一）三件套 2026/09 集中到期，续费 vs 新购的实测对账与迁移方案。
> **结论：不续费，新购 Flexus X 2核4G + 砍掉云数据库 RDS，年省 ¥2,588（降幅 52%）。**

## 一、结论：3 年省 ¥11,572（年省 ¥3,857，−77%）

四个方案统一年化后对比：

| 方案 | 含 RDS | 锁定 | 年化 | 3年总额 |
|---|---|---|---|---|
| 原样续费 | 是 | 1年 | ¥4,977.20 | ¥14,931.60 |
| 新购 Flexus X（已砍 RDS） | 否 | 1年 | ¥2,389.04 | ¥7,167.12 |
| 客服报价（ECS+RDS 3年包） | 是 | 3年 | ¥2,093.92 | ¥6,281.77 |
| **客服 ECS 3年包 + 砍掉 RDS** ⭐ | 否 | 3年 | **¥1,119.76** | **¥3,359.29** |

> **Flexus X 方案已被否决**：客服的 3 年包连 RDS 一起买都比它便宜。Flexus X 贵在 EIP 单独计费（5M 一年 ¥1,150），客服报价里 EIP 已打包。

省钱来自两处：

1. **砍掉云数据库 RDS** —— 3 年 ¥2,922.48，而三个库合计只有 **15MB**，合并回本机 MySQL 即可
2. **3 年包折扣 + 偏远区域** —— 乌兰察布一比北京便宜，包 3 年折扣远深于包 1 年

| 产品 | 规格 | 实际价 | 活动价 | 年化(活动价) |
|---|---|---|---|---|

**交叉验证**：在 ECS 自定义购买页实测 `x2e.2u.4g`（乌兰察布一）基准价 **¥102.60/月**，纯实例 3 年即 ¥3,693.60 —— 而客服报的 ¥3,359.29 还含 40G 高IO 盘与 5M EIP，确认是真折扣价。

**客服选得比原方案好的两点**：

- **AlmaLinux 9.4** 优于原建议的 Ubuntu 22.04 —— RHEL 系，与现有 CentOS 8 同源，宝塔迁移 / PHP 编译 / systemd 配置更平滑

## 四、待确认项（下单前必须查）

### 必须向客服追问（不确认这条，整个测算会塌）

- [ ] **「ECS 单买、不要 RDS，¥3,359.29 这个活动价还算不算？」** ← 捆绑活动价常常拆开就失效，这是最关键的一问
- [ ] 系统盘从 40GB 扩到 60GB 加多少钱
- [ ] 3 年包中途退订规则、能否升配
- [ ] 换到乌兰察布一后，**备案是否需要重新走流程**（同为华为云、接入商未变，但服务器 IP 与区域都变了）

### 自查项

- [ ] **备案**：同账号换服务器需在备案控制台**换绑备案授权码**到新实例，**必须最先启动**
- [ ] **月流量**：EIP 按带宽计费（非流量包），5M 是否够 —— 去 EIP 监控页看近 3 个月出网带宽峰值
- [ ] **延迟**：乌兰察布相比北京约 +10~20ms，对电商站可接受，但值得实测一次

## 五、迁移时间线（距 09/15 仅 27 天）

```
08/19-08/21  ① 备案授权码换绑申请        ← 最长路径，先启动
             ② 买新机（Flexus X，Ubuntu 22.04）
08/22-08/26  ③ RDS 三个库 dump → 新机本地 MySQL
             ④ 装宝塔，一键迁移 5 个 PHP 站点
             ⑤ django-jin 手工搬：venv 重建 + systemd
08/27-09/06  ⑥ 双机并行，用 hosts 指向新机验证
09/07-09/10  ⑦ DNS 切换（提前把 TTL 调到 60s）
09/15        ⑧ EIP + RDS 自然到期，不续      ← 硬节点
09/24        ⑨ 旧 ECS 自然到期，不续
```

> ⚠️ **09/15 是硬约束**：EIP 一到期旧机就没公网 IP，**会直接失去 SSH 和所有数据访问**。所有数据必须在此之前搬完。来不及就单独续 EIP 一个月做缓冲（约 ¥77）。

## 七、顺带要修的问题

| 问题 | 处置 |
|---|---|
| Django 用 `manage.py runserver` 跑生产 | 新机换 **gunicorn**（`gunicorn_conf.py` 现成的），别把开发服务器带过去 |
| 本机 MySQL 监听所有网卡 | 新机绑 `127.0.0.1` |
| 防火墙放行了 21 个端口，多数背后无服务 | 新机只开 22/80/443，按需再加 |
| `frps` 内网穿透服务在跑但 0 客户端 | 不迁 |
| `:6000` 反代到一个不存在的 Flask 应用 | 不迁 |
| 2 张 SSL 证书 2024 年就过期 | 新机用 Let's Encrypt 重签，过期的不要 |
| root 密码登录 + 安全 agent 会封禁高频登录 | 新机**只用密钥对**，禁用密码登录 |
| **MySQL 版本认证坑** | 旧机本地 MySQL 客户端是 **5.7**，ShopXO/ThinkPHP 老版本在 **MySQL 8** 默认 `caching_sha2_password` 下会连不上 —— 新机装 MySQL 8 需改认证插件为 `mysql_native_password`，或直接装 5.7 |
