## 公司 AI 编程工具采购调研

> 老板的三条要求：① 统一管理统一付费，员工自己注册公司报销；② 使用情况每月汇报；③ 开通 Claude Code + Codex + Kimi Code。
> **结论：这三条在任何单一平台上都凑不齐。分层是唯一解——国内平台做全员底座（能对公、能开专票、能出报表），核心几个人单独配 Claude 顶配。**
> 价格为 2026-08 官网实抓，标 ⚠️ 的是二手数字，下单前以支付页为准。

## 一、三家价格（只列决策要用的）

**Claude Code（美元）**

| 档位 | 价格 | 备注 |
|---|---|---|
| Pro | $20/月，年付 $17/月 | 含 Claude Code，额度最低 |
| Max 5x | $100/月 | **只有月付，没有年付** |
| Max 20x | $200/月 | 同上 |
| Team 标准席 | $25/席·月，年付 $20 | **2 席起**（7 月刚从 5 席降下来） |
| Team 高级席 | $125/席·月，年付 $100 | 额度约 6.25× Pro |
| Enterprise | $20/席·月 + 用量按 API 计 | **最低 20 席**，我们够不着 |

Free 档不含 Claude Code，网上说免费能跑的是老信息。

**OpenAI Codex（美元）**

| 档位 | 价格 |
|---|---|
| Plus | $20/月 |
| Pro | $100/月（5x）/ $200/月（20x） |
| Business | $20/席·月年付、$25 月付，2 席起 |
| Enterprise | 不公开，得联系销售 |

**这里有个坑**：Business 的 Codex 额度和 $20 的 Plus 完全一样，官方额度表逐格相同。多花的钱买的是 SSO、不拿数据训练、统一账单，**不包含用量报表**。

**Kimi Code（人民币）**

| 档位 | 价格 |
|---|---|
| Andante | ¥49/月 |
| Moderato | ¥99/月 |
| Allegretto | ¥199/月（重度实际起步档，K3 1M 上下文） |
| Allegro | ¥699/月 |
| Business 企业版 | **¥4,200/座·年（≈¥350/月），5 座起，¥21,000/年起** |

两个现实问题：Kimi 自 2026-07-19 起因算力**暂停新用户订阅**，到 8-23 没看到恢复公告，能不能买到得登录订阅页试；官方同时预告会员体系要改、Kimi Code 权益从会员里拆出来单卖，现价大概率要重构。别按现价做预算。

## 二、老板三条想法的可行性

### ① 「员工自己注册，公司协调付费」——在 Claude 和 Codex 上走不通

四个坎，每个都能单独卡死：

**付不了款。** 国内双币卡走 Stripe 按 BIN 直接拒付，工行 Visa、中行万事达都挂。Claude 结账页的国家下拉框里就没有中国。Claude Team 官方明文只收信用卡、不收 ACH/电汇，ChatGPT Business 自助版同理——「公司对公统一付款」这个动作在产品层面根本不存在，最后只能是某个人拿自己的卡刷。

**票不好使。** 拿到的是美元 invoice，能填公司抬头和税号，按国税总局 28 号公告可以做企业所得税税前扣除，但没有进项税可抵，严格说还有 6% 代扣代缴增值税的义务。而「员工个人注册 + 公司报销」抬头是个人，财务口径上属于个人消费报销，多数财务不认；变通成补贴又涉个税。

**条款上直接违约。** 这条最硬。Anthropic 2025-09-04 公告明文：**由不支持地区总部企业直接或间接持股超 50% 的实体，拒绝提供服务**——注册香港/新加坡子公司也不解决。中国大陆、香港、澳门都不在支持列表。OpenAI 的 188 国支持列表同样没有中国，官方原话是从不支持地区访问 "may result in your account being blocked or suspended"。公司名义签约等于合同第一天就是违约状态。

**封号不退钱。** Anthropic 透明度报告最新周期封了 1140 万个账号，申诉 39.8 万次翻案 4.2 万次，成功率约 10.6%。条款写明违规终止不退款、Team 移除成员也不产生退款或抵扣。另外 Anthropic 已上线 Persona 实名验证，社区一致反馈大陆证件走不通——钱付了、员工被抽到验证一样用不了。

**Kimi 这条能走，但有条款问题**：Kimi Code 权益页明写「本权益仅用于个人开发，非用于企业开发场景，如有企业需求请关注 Kimi 开放平台」。公司掏钱给全员买个人会员跑业务代码，条款上站不住。

### ② 「每月汇报使用情况」——只有 Claude Team 现成能做

Codex Business 和 Kimi Business 的团队版都拿不到成员级用量。这条需求直接决定买哪个档位，不是买了团队版就自动有的。详见第三节。

### ③ 「三家都开」——方向对，组合错

问题不是贵（虽然也贵：重度档 $100 + $100 + ¥199，一人一月 ¥1,650，10 人一年 ~20 万），而是 **Claude 和 Codex 是同一类风险资产**——都是合同禁止 + 随时封 + 不退款。同时开两家不是分散风险，是同时押两个可能归零的东西。

## 三、月度用量报表，谁能出

| 平台 | 成员级报表 | 怎么拿 |
|---|---|---|
| **Claude Team** | 有，最强 | 后台 Analytics + CSV 导出：邮箱、模型、请求数、tokens、花费；回溯 90 天，延迟 1 天。另有 Claude Code 专项看板（PR 数、代码行数、采纳率、cost per PR）。**坑**：席位额度内的用量不计美元，只有开了 usage credits 的超额部分才有钱数 |
| Codex Business | **没有** | 官方 feature matrix 里 Analytics dashboard / API / Compliance API 全标 unavailable。只有工作区级的花费上限，不是按人 |
| Kimi Business | **没有** | 角色只有管理员/成员两级，管理员权限里没有「查看成员用量」这项 |
| **Kimi 开放平台 API** | 有 | 一人一项目一把 Key，按项目导月度账单，还能设预算超限自动拒 |
| **阿里云百炼 / 智谱 GLM 团队版** | 有 | 云厂商标准账单，按席位和 Key 拆，一张增值税专票 |
| 任何个人订阅 | 没有 | 只能靠 `ccusage` 读本地日志，员工自报 |

**要按人出月报，路径只有两条：Claude Team，或者国内平台按 Key 拆账。**

## 四、推荐

### 主方案：国内底座（全员）+ Claude 顶配（核心 3 人）

**底座 —— 阿里云百炼 Token Plan 团队版，标准坐席 ¥198/席·月**（限时 ¥150，限时价只给包月）

- **客户端不用换**：百炼提供 Anthropic 协议入口 `https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic`，Claude Code 原样跑，只改 base_url 和 key，模型换成 Qwen3-Coder / GLM-5 / Kimi K2.5 / MiniMax，一张阿里云发票覆盖多家模型
- 对公转账、增值税专票、国内直连不用 VPN、不存在封号
- 每坐席 25,000 Credits/月，按 Key 拆用量，月报直接从阿里云账单导
- 10 席约 **¥1,500–1,980/月**

**顶配 —— 2~3 个核心开发配 Claude Code Max 5x（$100/月）**

- 个人注册，**只月付不年付**（封号不退款，年付等于押一整年）
- 公司按月以技能补贴形式发放，走福利/工资科目，不追求境外 invoice 抬头，公司不成为条款违约主体
- 用量靠 `ccusage` 自报，或者干脆不管——这几个人的产出本来就看得见
- 3 人约 $300/月 ≈ **¥2,160/月**

**10 人总盘子：¥3,700–4,150/月，年 ¥4.4–5.0 万。** 其中 ¥1.8–2.4 万是能开专票、能对公、能出报表的干净部分。

备选：智谱 GLM Coding Plan 团队标准版 ⚠️¥598/席·月（2 席起），也兼容 Claude Code（`https://open.bigmodel.cn/api/anthropic`），比百炼贵但模型是自家的 GLM-5.3。

### 备选方案：Claude 走云厂商

Claude Code 官方支持 Amazon Bedrock / Google Cloud / Microsoft Foundry 做后端。付钱给 AWS/GCP，拿云账单发票走正规服务贸易付汇，账单天然按 key 出量，也不吃消费级风控那套（IP 跳变、拼车检测都不适用）。

代价：按 token 计费，官方给的企业侧经验值 $150–250/开发者·月，10 人就是 **¥1.1–1.8 万/月，年 13–21 万**，是主方案的 3–4 倍。而且 AWS/GCP 国际账号对中资控股公司同样可能在合规审查后拒户，开户能不能过要先实测；AWS 中国区没有 Bedrock，必须走国际区。

如果 Claude 模型对我们不可替代且预算能接受，这是唯一「合法拿发票 + 不怕封号」的 Claude 路径。建议先用一个人的量试跑一个月，用真实账单反推 10 人成本。

### 明确不做

- 以公司名义签 Claude Team / Enterprise（股权条款直接排除 + 不收对公款 + 一封全灭不退款）
- 任何形式的年付
- 公司资金走代充平台（账号法律上不归公司，上游常是盗刷卡链，票货不符属虚开风险区）
- 多人拼一个 Max 账号（条款明文禁止共享凭据，多 IP 并发是风控头号特征）

## 五、风险

1. **合同层面就违约** —— Anthropic 明文拒绝中资持股 >50% 的实体（含其海外子公司），OpenAI 支持国家列表也无中国。公司名义采购不是擦边，是明确违约。
2. **封号不退款，申诉成功率约 10.6%** —— 年付等于把整年预算押在一个随时可判违约的账号上。
3. **对公付款在产品层面不存在** —— Claude Team 和 ChatGPT Business 都只收卡不收电汇，国内卡过不了 Stripe，美元 invoice 无进项可抵还悬着代扣代缴。
4. **Kimi 现在可能买不到、价格还要变** —— 7-19 起暂停新用户订阅至今未恢复，且官方预告 Kimi Code 权益要从会员里拆出来单卖。
