## 三、采集方法与命令（复现用）

```bash
# 登录（Windows OpenSSH，端口 22；密码已脱敏）
sshpass -p '【已脱敏】' ssh smart_vision@192.168.66.137

# 系统版本 + 网卡/IP（一条命令全出）
systeminfo

# CPU / 显卡 / 硬盘 / 主板 / 内存（Win11 已移除 wmic，改用 CIM）
powershell -NoProfile -Command "Get-CimInstance Win32_Processor | fl Name,NumberOfCores,NumberOfLogicalProcessors,MaxClockSpeed"
powershell -NoProfile -Command "Get-CimInstance Win32_VideoController | fl Name,AdapterRAM,DriverVersion"
powershell -NoProfile -Command "Get-CimInstance Win32_DiskDrive | fl Model,Size,InterfaceType"
powershell -NoProfile -Command "Get-CimInstance Win32_BaseBoard | fl Manufacturer,Product"
powershell -NoProfile -Command "Get-CimInstance Win32_PhysicalMemory | fl Capacity,Speed,PartNumber"

# 分区使用率
powershell -NoProfile -Command "Get-PSDrive -PSProvider FileSystem | fl"

# Windows 输出为 GBK 编码，管道转码后可读
# <上述命令> | iconv -f GBK -t UTF-8
```

## 四、踩坑记录

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 连 192.168.66.139 报 No route to host，ARP 解析 FAILED（同网段其余 21 台主机正常） | 该 IP 已下线：机器走 WiFi+DHCP，IP 漂移 | 实际 IP 为 192.168.66.137；排查判据 `ip route get` + `ip neigh` |
| SSH 远程执行 `head`/`grep` 报「不是内部或外部命令」（GBK 乱码） | 目标是 Windows，默认 shell 为 cmd，无 Unix 命令 | 改用 `systeminfo` / `powershell -Command` |
| `wmic` 执行无任何输出 | Win11 新版本（24H2+）已移除 wmic | 统一改用 `Get-CimInstance` |
| 远程命令的中文输出全是乱码 | Windows 控制台输出 GBK 编码 | 管道接 `iconv -f GBK -t UTF-8` |
