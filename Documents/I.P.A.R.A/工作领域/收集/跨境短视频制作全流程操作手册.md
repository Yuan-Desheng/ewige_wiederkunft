## 一、原理

**目标**：把「商品图 + listing +（可选）爆款视频」做成 9:16 竖屏带货短视频，先在办公室显卡免费出验证片，满意再花云端额度出高清。

**四条入口（先选路，再动手）**：

```text
商品库建条目（主图 + listing 必填）
        │
        ├─ 有一条对口的爆款视频 ──► 商品页「📹 仿爆款」      流程 2.1  照它的时间轴重拍，主体换成我们的产品，不需要脚本
        ├─ 有爆款、只想借节奏镜头 ──► 商品页「🔬 拆解爆款再拍」 流程 2.3  系统拆成「镜头1/2/3…」脚本，再按脚本拍
        ├─ 没有参考视频、自己有分镜 ──► 商品页「📝 按脚本拍」    流程 2.2  脚本必选，按「镜头1：…」写
        └─ 只有几张图 + listing    ──► 商品页「🪄 图文直出」    流程 3.5  副驾从要点写到脚本再到出片，最快上手
```

**制作台四步**（2.1 / 2.2 / 2.3 都会落到这里）：

```text
① 选商品  →  ② 定拍法  →  ③ 素材与说明（图 / 画幅 / 时长 / 管线 / 口播 / 让副驾写说明）  →  ④ 确认提交
                                                                                              │
                                                                                              ▼
                                                                    GPU 队列（5090 优先，4090 兜底）
                                                                                              │
                                                                                              ▼
                                              待确认：看验证片 → 裁判分 → 下载/采用/出高清/再来一版
```

**两级出片**：本地验证档免费（2–7 分钟一条，15 秒 D 极速实测约 1–2 分钟）；云端高清按秒计费，只在确定要用的片子上点「出高清」。

## 二、素材准备

开工前凑齐这三样，缺 listing 或主图时副驾会瞎编规格——**规格数字宁可空着，不要手填没依据的参数**。

### 2.1 最低清单

| 物料 | 数量 | 要求 | 没有会怎样 |
| --- | --- | --- | --- |
| 正面主图 | 1 张，必填 | 干净、主体完整、同一配色；这张会变成 `<Picture 1>`（主体锚点），成片外观以它为准 | 成片漂款、漂色 |
| 多角度 / 细节 / 特点图 | 建议 2–5 张，合计 ≤6 张（图文直出上限）/ 制作台可再加 | 同一件、同一配色、同一印字；侧 45°、结构特写、使用场景各 1 张最好 | 件数/卡扣/纹理被模型脑补 |
| 平台 listing | 整段粘贴 | TikTok Shop / 亚马逊后台原样复制：标题 + 描述 + 卖点 + 规格（尺寸/材质/数量） | 口播和卖点对不上真实商品 |
| 爆款参考视频 | 仿拍必填；图文直出可无 | mp4 / mov，≤200MB，时长 ≥ 成片时长 + 1 秒（做 15 秒片至少 16 秒素材） | 只能走「按脚本拍」或「图文直出」 |

SKU 图（不同配色 / 不同印字）**不要混进同一条视频**。模型会把送进去的每张图当成同一件商品的不同角度。

### 2.2 图从哪来、怎么洗

1. 1688 / TikTok 商品页 / 自己拍，先下到本地。
2. 打开 **素材库** 或商品详情，上传；分类选「产品图 / 场景图 / 特点图」。系统会自动判一遍，判错了在下拉里改，改过的会记住。
3. 图上有中文促销大字、水印、杂乱背景：走商品页「🪄 图文直出」里的素材体检 → 对该图点「🪄 处理」（约 20–40 秒）。处理结果：去掉**背景上的营销字**（商品自身印字、品牌标保留），把商品抠到干净浅灰底。新图挂在原图下面，原图不动，两张都能选。
4. iPhone 拍的 HEVC 视频直接传，服务器会转成通用格式。

**挑图口诀**：正面必须有、侧面最好有；白底/浅底优于场景杂图；分辨率低于约 600px 的丢掉；不要拿带手机界面的截图当产品图（界面会被学进成片）。

### 2.3 爆款视频怎么准备

1. 打开 **素材库** → 「⏬ 从链接下载爆款视频」。
2. 把 TikTok / YouTube 链接一行一条贴进去，选「关联商品」，点下载。后台几秒到几十秒完成。
3. 也可以本地点「上传素材」，分类选「爆款视频」。
4. 仿拍时在制作台点「📁 从素材库选」，只列出分类为爆款视频的 mp4/mov；本商品的优先。

选片标准：动作清晰、单一主体、运镜稳定、有手入镜演示（翻转 / 卡扣 / 撕拉）。UGC 信任感在手上，除内衣类外提示词里要有手。

### 2.4 商品条目里要填什么

路径：工作台「📦 新建商品」或 商品库右上角新建。带 `*` 的是中文名，其余建议一次填全——副驾写说明时以这些为准。

| 字段 | 怎么填 |
| --- | --- |
| 负责人 | 自己的名字，方便「只看我负责的」筛选 |
| 类目 | 如：户外运动 |
| 商品中文名 * | 短、能在列表里认出来 |
| 商品英文名 | 可点「✨ 中译英（含卖点）」 |
| TikTok 商品链接 | 有就填 |
| 客单价 / 选品原因 / 目标人群 / 目标市场 | 目标市场常用「新加坡 + 马来西亚」 |
| **平台在售 listing** | **最重要**：从后台整段粘过来，什么语言都行 |
| listing 语言 | 马来文 / 英文 / 印尼文 |
| 应用场景、卖点中/英 | 有就填；英文卖点会进视频文案 |

保存后进入商品详情，顶部四个按钮就是创建任务的入口。

## 三、逐步操作：从哪里创建任务、选项怎么选

### 3.0 登录

1. 打开外网或内网地址，用自己的用户名登录（`yuandesheng` 等）。
2. 首次登录后点左下角「改密码」，填真实姓名。
3. 手机浏览器可直接用。

### 3.1 推荐起点：商品详情页四个按钮

商品已经建好、图已经传上之后，**从商品详情页出发**，不要空着手进制作台再搜商品。

| 按钮 | 跳转 | 什么时候点 |
| --- | --- | --- |
| 📹 仿爆款 | `/maker?product_id=…&flow=2.1` | 素材库里已经有一条对口爆款视频 |
| 📝 按脚本拍 | `/maker?product_id=…&flow=2.2` | 没有参考视频，自己写（或已有）分镜脚本 |
| 🔬 拆解爆款再拍 | `/maker?product_id=…&flow=2.3` | 有爆款，只借镜头设计和节奏，不抄台词和品牌 |
| 🪄 图文直出 | `/plan?product_id=…` | 只有图 + listing，想让副驾从要点写到出片 |

其他入口：工作台「🛠 新建制作任务」进空白制作台；商品列表每行「去制作」。

### 3.2 制作台 ① 选商品

搜索中文/英文名，或勾「只看我负责的」。点卡片选中 → 下一步。

### 3.3 制作台 ② 定拍法（二选一，这一步决定后面要不要脚本）

**有爆款参考视频 → 仿拍（2.1）**

1. 「📹 点击选择 mp4/mov」本地上传，或「📁 从素材库选」。
2. 不需要脚本。可点「✨ 从参考视频仿写口播」（借节奏和开场方式，不抄内容）。
3. 想改成按脚本拍：点「✖ 不用这条视频」或「🔬 拆解成脚本」（约 20–40 秒，写出「镜头1/镜头2…」，不抄原片台词、价格、品牌）。

**没有参考视频 → 按脚本拍（2.2）**

1. 点一张已有脚本卡片，或「＋ 新建脚本」。
2. 脚本按「镜头1：… 镜头2：…」写，一条一个画面，写清**画面里发生什么、产品怎么出镜**；**不写台词**（口播另填）。
3. 标题 ≤14 字，如 `草坪野餐·杯架卖点`；市场可空。

两样都没定，下一步按钮是灰的。

### 3.4 制作台 ③ 素材与说明（选项在这里选）

按从上到下的顺序做，**先定出片设置再让副驾写说明**——说明和口播都按这些来。

**图片**

- 默认只带 1 张主图当主体锚点（卡片标「★ 主体锚点」，对应 `<Picture 1>`）。
- 「📁 从素材库选」加角度图 / 场景图 / 特点图；点缩略图看大图，确认印字和配色。
- 换主体：在目标图上点「设为主体」。
- 系统发现不是同一件会弹「⚠️ 有图和主体不是同一件」→ 优先「去掉这几张，继续生成」。

**出片设置（下拉框原样）**

| 字段 | 选项 | 日常选 |
| --- | --- | --- |
| 画幅 | `9:16 竖屏` / `16:9 横屏` | **9:16 竖屏**（TikTok 竖屏相对 letterbox 转化更高） |
| 时长 | 5 / 10 / **15（默认）** / 20 / 30 秒 | **15 秒**。团队基本不做 10 秒以内 |
| 出几条 | 1 条（默认）/ 2 条挑 1（GPU×2）/ 3 条挑 1（GPU×3） | **1 条**。赶时间别选 2/3；要评测再选 2–3，裁判会标「⭐ 裁判推荐」 |
| 出片管线 | A 标准 / B 快速 / C 智能 / **D 极速**（可多选） | **D 极速**。多选 = 评测模式，同素材并排对比 |

管线对照（5 秒片、2026-09-08 同素材实测）：

| 管线 | 名称 | 原理 | 5 秒耗时 | 15 秒 D 档近期实测 | 适合 |
| --- | --- | --- | --- | --- | --- |
| A | 标准画质 | 25 步、无加速 | ~7 分钟 | — | 画质基准、高要求 |
| B | 快速 | turbo 8 步 | ~3 分钟 | — | 保守稳妥 |
| C | 智能 | turbo8 + Sage | ~2 分钟 | — | 比 B 快约 32% |
| D | 极速 | turbo8+Sage+TE-Speed | ~1.5 分钟 | 4090 约 2 分 10 秒 / 5090 约 1 分 2 秒 | **日常默认** |

15 秒片大约是 5 秒的 4 倍时间。两条显卡自动分工：5090 优先、4090 兜底。任务页显示预计耗时。

**口播台词**

- 用中文写，提交时自动译成英文。留空则不出人声。
- 仿拍可点「✨ 从参考视频仿写口播」。
- 字数随时长变，框下会提示区间；超了会糊或被截尾。

**配音方式（15 秒以上才出现完整选项）**

| 选项 | 效果 | 日常选 |
| --- | --- | --- |
| 后期配音（`vo_route=tts`） | 逐字准确、可选音色、自动压英文字幕（下三分之一白字黑边）；画面里的人不开口 | **默认，追求准确用这个** |
| 模型原生口型（`vo_route=native`，实验） | 人物开口、口型对上；声音由模型定；每 10 秒一段最多 40 词；出片后**不能**改口播重配 | 追求真人感再试 |
| 配音装不下时让副驾自动压缩口播 | 只删次要句子，不加新内容；出片后任务页还能手改重配 | **默认勾上** |

10 秒及以内：模型自带人声，按提示的字数写。超过 10 秒：画面无声，系统用 TTS 配。

**配音音色**：默认「🎯 自动匹配」（按说明里人物性别/年龄选）。下拉约 30 个，点「🔈 试听」。出片后任务页还能换音色重配。

常用音色（`/api/tts/voices`）：

| 分组 | 名称 |
| --- | --- |
| 青年女 | 活力女孩、明快女声、甜美女孩、温柔女孩、魅力女声 |
| 中年女 | 沉稳女声、自信女声、优雅女士（英式）、平静女声、有说服力的女士 |
| 年长女 | 睿智年长女士、感性年长女士 |
| 青年男 | 可信赖青年男声、温柔男声、体面青年、友好小伙、开朗男声、澳洲小伙 |
| 中年男 | 磁性男声、低沉男声、低音绅士、可靠导师、耐心男声、成熟男声 |
| 年长男 | 睿智老学者、讲故事的长者 |
| 少年 | 少年、倔强男孩 |
| 旁白 | 旁白（男，有表现力）、旁白（女） |

**产品信息**：从商品库带出。要临时改点「改一下」，只影响本次，不回写商品库。

**生成说明（给模型的拍摄指令）**

1. 图、出片设置、口播都定好后，点「✨ 让副驾写说明」（多位写手各写一版、互相审稿，约 1–3 分钟）。
2. 上面显示中文对照（只读）；要改就在「修改意见」用中文写，例：`第二个镜头改成坐下拧开水瓶；人物换成一对年轻情侣；环境改成夜市`，点「✏️ 按意见修改」。勾了「🔒」的镜头副驾改不到。
3. 懂英文可「展开英文原稿」直接改，停手 2 秒自动校验。**段名 `【…】` 和 `<Picture N>` 不要动。**
4. 改了图、设置或脚本，旧说明会标「已过期」，点重写。
5. 选了脚本时，副驾会先核对脚本和图是否对得上（脚本写 PARIS、图是 BOSTON 这种），给出修改版；可选「保留原脚本」。

日常路径：**让副驾写，用修改意见微调**。手写英文提示词只在展开原稿时用，完整范例见第四节。

### 3.5 制作台 ④ 提交

看摘要（商品 / 脚本 / 口播 / 生成说明 / 画幅时长 / 管线 / 素材）→「🚀 提交制作」。任务进 GPU 队列。提交的是本地验证档，免费。

### 3.6 图文直出（只有图时走这条）

商品页点「🪄 图文直出」。

1. **选图**：点选，点的顺序就是 `<Picture N>`，第一张 = 主体。多 SKU 只留目标款，最多 6 张。
2. **目标市场**：新加坡+马来西亚 / 泰国 / 菲律宾 / 越南 / 印度尼西亚。默认新马。
3. **时长**：默认 15 秒。
4. **补充要求**（选填）例：`前 3 秒直击久坐办公室闷热出汗的痛点；人物用 30 岁左右马来裔上班族`。
5. 点「✨ 让副驾策划」。先跑素材体检（约 5 秒）：每张图标 ✅ / ⚠️ / ❌。有问题的图可「🔄 换图」或「🪄 处理」。
6. 「✅ 按建议继续策划」或自己勾「用」哪些图再继续。勾「自动模式」则体检不停，自动换主体、去掉不同款、处理有问题的图。
7. 策划结果（约 20 秒，全部可改）：脚本标题、适合人群、5 大要点、痛点、前 3 秒钩子、分镜脚本、英文口播。
8. 「🎬 一键出片」= 存脚本 → 副驾写说明（1–3 分钟）→ 进 GPU 队列 → 跳任务页。也可以「去制作台微调」再提交。

中途看到「网络中断 / Load failed」：脚本已经保存，点「去制作台继续」，不用重来。

### 3.7 任务中心：验证片出来之后

状态：排队中 → 验证中 → **待确认** →（高清中）→ 已完成 → 已发布。失败会写原因。

排队中能看到第几位、预计等多久；可以取消。验证中每 8 秒自动刷新。显卡上午归运营用，下午可能暂停派发，到点自动继续，不用重新提交。

待确认时按这个顺序做：

1. **先看 7 位 AI 裁判**（像不像、印字、动作、画面、口播、前 3 秒钩子、配色）。裁判是参考，采用权在你；「印字错 / 动作没演」一般准。
2. 裁判说「可以看」→ 选下面的动作。
3. 裁判说「改说明重跑」→「✏️ 按裁判建议改一版」（回制作台，建议自动进修改意见；没点名的镜头默认锁定）。
4. 裁判说「换种子重跑」→「🎲 换种子重跑」。
5. 裁判说「素材有问题」→ 回商品页换图。

四个采用动作：

| 按钮 | 含义 |
| --- | --- |
| ⬇ 下载验证片 | 下载前先打 1–5 星 + 标签（商品不像 / 动作不对 / 口播有问题 / 画面有瑕疵 / 节奏不对 / 可以用）+ 一句评语 |
| ✅ 直接采用验证片 | 标成成片，不花高清的钱，以后还能补出高清 |
| 🌐 出高清 | 云端 768P / 2K，按秒计费，会显示预估费用 |
| 🔁 不满意，再来一版 | 带着全部参数回制作台，沿用同一个种子，只改你动过的地方 |

## 四、脚本 / 口播 / 提示词

制作台上**真正发给模型的是副驾写的英文说明**。运营日常写两样就够：分镜脚本（中文）和口播（中文）。下面给出可直接复制的模板，以及两条完整成稿（一条来自线上任务 #183，一条来自本地 skill 定稿）。

### 4.1 脚本怎么写

制作台新建脚本的占位符就是标准格式——**一条镜头一句话，写画面和产品出镜，不写台词**：

```text
镜头1：草坪上，年轻男子从收纳袋里抽出折叠椅，一甩展开放到地上。
镜头2：他坐下靠住椅背，把矿泉水瓶插进右侧扶手杯架，冲镜头点头微笑。
```

15 秒推荐三段（钱花在中段 8 秒）：

| 镜头 | 时间 | 干什么 |
| --- | --- | --- |
| 镜头1 Hook | 00:00–00:03 | 痛点/惊叹，先让人「我也这样」，产品还不是主体 |
| 镜头2 Demo | 00:03–00:11 | 硬核演示：翻转、卡扣、同框对比、手入镜操作 |
| 镜头3 CTA | 00:11–00:15 | 多色/规格 + 折扣口播；黄车指引留给后期或口播 |

三种验证过的爆款范式（三选一）：痛点情景 → 朋友推荐 → 卖点 → CTA；劣质对比 → 硬核测试 → CTA；质疑市面 → 数据对比 → CTA。能做**同框对比**（擦过/没擦同时出现）的品优先。美妆/保健类目不做 before/after 疗效对比（SG listing 禁）。

线上商品「跑步腰袋」脚本库里的真实例子（15 秒、纯产品、无人声——可当「无口播静物片」参考）：

```text
【15 秒 TikTok 竖屏 9:16，纯产品展示，无人物，轻快运动 BGM，英文字幕叠加，无人声】
0-3s：腰包平放特写，镜头快速推向腰包主体。字幕：Anti-bounce running waist bag🔥。明亮简约运动背景，突出腰包外观。
3-6s：特写拉开主拉链，把大屏手机放进去，拉上拉链。字幕：Large capacity for big phone。展示主仓空间。
6-9s：打开副小隔袋，放入钥匙卡片，展示多分区。字幕：Multi-pockets for keys & cards。
9-12s：镜头依次扫过透气背布、反光条、顺滑拉链特写。字幕：Sweat-resistant fabric・Reflective strip。
12-15s：腰包缓慢 360 度旋转展示，右下角弹出商品卡片框。字幕：Lightweight for running & gym ✨ Shop now。
```

有口播的片子：脚本里的「字幕：」行可删，改到口播框；屏幕大字由系统在 15 秒后期配音片上自动压英文，或后期自己烧。

### 4.2 口播怎么写

制作台占位符：

```text
这款露营椅两张才 59 块，一秒收纳，露营野餐都能用
```

价格、克数、米数**必须来自 listing 或图上看得见的内容**，没有就不要写。

字数区间（系统按中文字数卡，英文按词数；中译英约 1.4 字/词）：

| 时长 | 配音 | 中文字数大约 | 英文词数大约 |
| --- | --- | --- | --- |
| 5 秒 | 模型原生 | 22–31 | 16–22（上限 40） |
| 10 秒 | 模型原生 | 45–56 | 32–40（上限 40） |
| 15 秒 | 后期 TTS | 39–55 | 28–39 |
| 20 秒 | 后期 TTS | 53–73 | 38–52 |
| 30 秒 | 后期 TTS | 80–109 | 57–78 |

15 秒三段口播句库（每段一句，全片大约 33–38 个英文词）：

```text
Hook：手机那点光，真要用的时候就没了。
Demo：一百米光柱，变焦远近都能调，一个键三种模式。
CTA：Type-C 充电，塞进外套口袋。点下面黄色小黄车。
```

对应英文（副驾会译；自己改英文原稿时用这个量级）：

```text
Your phone light dies right when you actually need it.
Hundred metre beam, zoom it tight or wide, three modes on one button.
Type-C charging, fits your pocket. Tap the yellow cart.
```

### 4.3 副驾说明的结构（展开英文原稿时认这些段名）

线上副驾当前产出的段名如下，**改的时候段名和 `<Picture N>` 原样保留**：

```text
【reference images】   每张图干什么、主体以哪张为准、忽略图上烧录的营销字
【environment】        场景、光线、画幅
【character】          有没有人、手的描述；无人就写 No people
【action】             【action 1】/【action 2】/【action 3】 按时间推进
【constraints】        无字幕、无水印、忽略参考图营销字、画幅
【product constraints】配色 / 形状 / 五金 / 功能 / 材质，全部从图上锁死
```

本地 CLI skill（办公室 4090 直出、不走制作台）用另一套六段：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description`（`[Shot 1]` / `[Shot 2] At 00:03.000` / `[Shot 3] At 00:11.000`）/ `overall_soundscape` / `non_diegetic_music`。制作台里一般看不到这套，只有自己跑 `h3_local.py` 时才用。第四节 4.5 给完整定稿。

### 4.6 三条铁律（改说明时对照）

1. **口播按镜头分。** 脸在画面里对观众说话：写对镜、口型同步、自然眨眼。产品特写没有脸：写画外音，并写 `his face is not in this shot`。脸在画面里却写「嘴唇不动」，会出恐怖谷。
2. **商标从成片里拿掉。** 1688 参考图上的牌子是供应商的。正向写表面留空；负向禁 logo / wordmark / lettering。两个文件里都不要出现商标本身的拼写。
3. **产品防漂移：正面写清它是什么，反面写死它不是什么。** 例：手电筒写「只有一圈银边在灯头、恰好两颗键、恰好四颗电量灯」；匹克球拍写「拍面不弯曲、不是网球拍、不是光柄」。

仿拍时在说明里二选一：

```text
借节奏：
<Video 1> is the pacing reference; replicate its shot rhythm and cut timing, not its footage, subjects, or branding.

整场仿制（效果最好，版权敞口最大）：
Recreate the exact scene from <Video 1>. The ONLY change is to replace [原主体] with the product from <Picture 1>. Keep everything else identical to <Video 1>.
```

制作台选「仿拍」时副驾默认走时间轴重拍；选「拆解成脚本」则只借镜头设计。出片后逐帧看一遍，确认没有原片人物/包装/水印泄漏。

## 七、踩坑记录

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 成片配色/印字和主图不是一件 | 混进了别的 SKU 图，模型把所有图当同一件 | 只留一张主图，或按弹窗去掉冲突图 |
| 成片漂出多余卡扣、第二圈银边、商标乱码 | 产品约束没写死；参考图有营销字/商标 | listing 和图上可见的细节写进商品描述；图文直出「处理」去字；负向写死「它不是什么」 |
| 没有人声 | 口播留空；或 15 秒片人声是后期配的，验证片刚出来还没配上 | 任务页口播卡片点「重新配音」 |
| 口播句尾被截 / 念不完 | 字数超过该时长的 TTS 预算 | 「副驾压缩建议」或「自动优化并重配」，画面不用重出 |
| 10 秒以内没有字幕 | 字幕只压在 15 秒以上后期配音片上 | 短片后期自己烧，或改 15 秒 |
| 页面 Load failed | 长请求超时 | 已做的步骤都保存了；策划页点「去制作台继续」 |
| 参考视频传不上 | 不是 mp4/mov、超过 200MB、短于成片时长+1 秒 | 转格式、压缩、换更长的片 |
| 上传 mp4 浏览器打不开 | iPhone HEVC | 照常上传，服务器自动转 |
| 排队很久 | 前面有任务，或队列被暂停 | 看任务页位次；下午可能暂停到次日上午 |
| 出高清提示 API Key 未配置 | 云端密钥未配 | 找 admin；本地验证档不受影响 |
| 想只改一个词重跑，结果整段变了 | 新开了一条任务、换了种子 | 用「再来一版」，沿用同一个种子 |
| 裁判分和肉眼不一致 | 裁判看 8 帧抽样 + 口播回读 | 以你的判断为准；印字错/动作没演一般听它的 |
| 方片 / 像品牌广告片 / 一个长镜头后半段变形 | 走了图生视频端点或提示词写成电影感连续长镜头 | 制作台已经锁 9:16 + 分镜；手改英文时写硬切时间码，不要写 `A single continuous shot`、`cinematic`、`moody lighting` |
| 脚本被改了 | 副驾发现脚本和图对不上 | 看修改版；可「保留原脚本」 |
| 删了商品找不到 | 删除只是隐藏 | 管理员在「商品回收站」找回 |

首轮避开的品类：保健品（SG HSA / MY MAB+KKLIU）、内衣近身、儿童近景人脸、三丽鸥等 IP。内衣静物必须写 `no human body, no mannequin`。
