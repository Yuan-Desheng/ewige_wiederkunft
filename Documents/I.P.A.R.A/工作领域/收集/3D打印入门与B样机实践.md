## 3D打印入门与B样机实践

```meta-bind-embed
[[笔记抬头模块]]
```

这篇写给第一次接触3D打印、或者想了解B样机进展的人。先看我们做出了什么、它有什么用，再按需要阅读操作步骤和技术代码。

## 一、这台打印机在项目里做什么

原德胜负责的B XLeRobot Basic是一台双臂移动操作机器人。它由机械臂、舵机、轮子、相机、推车和连接结构组成。采购解决现成部件，3D打印则制作模型中设计好的支架、固定座和连接件，让这些部件能够按预定位置装在一起。

拓竹A1是本次使用的打印机。它把塑料耗材加热后，通过喷嘴按设定轨迹逐层堆叠，形成零件。这类方法称为熔融沉积打印（FDM）。我们需要分别判断“零件是否打印成形”和“能否与实物部件装配”，两者都通过后，才继续验证整机动作。

| 对象 | 在这件事里的作用 |
| --- | --- |
| B XLeRobot | 要完成装配与调试的机器人，原德胜负责到货核对、装配牵头、调试及后续问题处理。 |
| 拓竹A1 | 制作塑料零件的工具，本身不是B机器人的组成部件。 |
| STS3215舵机 | 采购来的执行部件；打印固定结构需要与它的实物尺寸匹配。 |
| Gauge_0试件 | 在制作大批结构件前，用于检查与舵机配合的小工装；不装入机器人。 |

## 二、为什么先打印一个小框

这次打印的Gauge_0看起来是一个带“0”标记的小框。它的工作是帮助判断打印后的尺寸能不能与STS3215实物合适地配在一起。

![[Extras/3D打印/2026-11-03-Gauge_0白色成品.jpg]]

先做小试件，可以较早发现配合过松或过紧的问题。否则，完整机械臂结构即使外观看起来正常，也可能在装舵机时才发现不合适，导致大件返工。因此，这件工装属于B样机的打印准备工作。

本次确认的进度是：**Gauge_0已完成打印并取下，用户已用STS3215试配并确认“可以卡进去，严丝合缝”，本样件初步配合合适。** 这不代表B样机的机械臂、底盘或全部打印件已经完成。

## 三、一个模型怎样变成可用零件

```mermaid
flowchart LR
    A[选择模型文件] --> B[核对材料与打印设置]
    B --> C[切片：生成喷嘴运动路径]
    C --> D[打印并取下实物]
    D --> E[检查外观和尺寸配合]
    E --> F[用于后续装配]
```

“切片”是把三维模型转换成一层一层的打印路径，并计算温度、速度和用料。我们使用Bambu Studio完成这一步。打印机再按照生成的指令执行加热与运动。

| 常见名称 | 阅读时可以这样理解 |
| --- | --- |
| STL | 主要描述模型形状；它本身不能说明这台机器应使用什么材料和温度。 |
| 3MF | 可以保存模型、设置等工程信息；文件中具体有什么要检查。本次下发的切片包还包含G-code。 |
| G-code | 打印机执行的运动、加热等指令；由切片软件生成。 |
| 耗材 | 打印所用的塑料料丝。本次实际使用PETG Basic。 |
| 首层 | 打印在板上的第一层，需要现场观察是否正常附着和出料。 |
| 试配 | 用实际部件检查松紧与安装关系；不能只靠模型预览或成品照片代替。 |

## 四、这次打印的结果怎样解读

2026年11月3日，本次任务以“工装——B样机舵机配合试件”登记内容整理，人员为原德胜。启动指令在13:07发出，设备返回成功并进入运行流程；用户随后确认正常打印，之后提供了完成屏幕与取下的试件照片。

![[Extras/3D打印/2026-11-03-Gauge_0打印完成屏幕.jpg]]

| 已有证据 | 可以得出的结论 |
| --- | --- |
| 屏幕显示“打印完成” | 本次打印任务已完成。 |
| 屏幕显示0h28m、4g | 记录为设备显示的28分钟和4克；4克不是称重实测。 |
| 取下的白色外观试件照片 | 零件已成形并取下，照片中外框完整；不能据此验收精确尺寸或底面平整度。 |
| 用户提供套入照片并称“严丝合缝” | 本次插入配合紧实，初步合适；数值公差、取出力及强度未测量。 |

切片前估算是28分26秒、4.62克。估算与完成屏幕的显示精度、统计口径可能不同，保留两者各自的含义即可。照片文件名中的13:48是拍照线索，不是打印机的准确结束时刻。

## 五、参数不是一张通用配方

下面解释这次几个主要数字。它们适用于本次A1、PETG Basic和Gauge_0组合；换材料、喷嘴或零件后，应重新核对并切片。

| 本次参数 | 它决定什么 |
| --- | --- |
| 0.4 mm喷嘴 | 喷嘴出口的标称直径，是选择匹配打印机配置的重要条件。 |
| 0.20 mm层高 | 每层的高度；本模型高10 mm，对应本次50层。 |
| 2道墙 | 外壳轮廓的壁线设置，影响结构与用料；不能只看填充率判断零件强度。 |
| 15%填充 | 内部填充的设置，不代表整个模型全部实心，也不等于成品总密度就是15%。 |
| 无支撑 | 本次没有添加额外支撑；其他支架是否需要支撑，要看其结构与朝向。 |
| 喷嘴240°C、热床70°C | 本次模型打印设置；启动时会有预热、清料和校准阶段，屏幕温度可能暂时不同。 |

本次按当前上机卷与本人要求使用PETG Basic。B其他结构件原计划仍为PLA+，这次没有把它们一起改成PETG。材料和参数会影响配合结果，后续用PLA+制作结构件时，应再用相同材料与相应参数验证。

## 六、接下来只推进一次实物配合验证

1. 准备一颗断电的STS3215。按本次实物照片，输出轴在左，白框竖起、“0”小耳朝上，从舵机右端轻轻套入一小段，测试机身端部配合，不强压或靠螺丝硬拉。方向图见[[Documents/I.P.A.R.A/工作领域/收集/拓竹A1使用与PETG首件打印记录#Gauge_0如何使用，以及能否继续下一件|Gauge_0试配说明]]。
2. 记录偏松、合适、偏紧，最好拍清接触位置。若不合适，先核对模型版本、打印比例与参数，再决定是否返工。
3. 根据结果安排下一件。配套Gauge_tight_1现已按同PETG参数离线切片，预计28分29秒、4.61克，尚未上传或启动。若Gauge_0明显偏紧或偏松，先排查；进入正式结构件前，需确认实物配合合适。

这一步的重点是得到装配证据。下一阶段的目标才是完成一条从臂试装，再逐步配齐另一条臂、相机支架与底盘结构。

## 七、打印后怎样归类和收纳

这个小框记作“Gauge_0舵机尺寸配合试件”，类别是B项目的自制工装。它帮助判断装配松紧，今后还可用来对照同一材料与设置的打印结果。

按照原来“按机型分箱、分袋贴标”的办法，建议放入B箱的B-结构区域，并新增独立的“工装/试件”袋。袋上写模型名、PETG Basic、1件、打印日期、负责人和“已试配，初步合适”。新增工装袋是补充建议，实际是否已放入尚未确认。

先保持试件平整、与散装紧固件分开；完成舵机试配后再更新袋上状态。可直接使用[[Documents/I.P.A.R.A/工作领域/收集/拓竹A1使用与PETG首件打印记录#当前试件的归类与收纳建议|首件记录中的标签文本]]。
