## 二、核心流程（七环节）

| 环节 | 做什么 | 对应页面 |
| --- | --- | --- |
| 选品 | 录入商品（卖点、目标市场、参考链接） | 商品库 |
| 备料 | 上传/下载爆款视频、产品图 | 素材库 |
| 拆解 | 把爆款视频的镜头语言写成脚本 | 脚本库 |
| 制作 | 选商品 + 选脚本 + 传素材 → 一键仿拍 | 制作台 |
| 验证 | 本地显卡免费出片，先看效果 | 任务中心 |
| 出高清 | 满意后调云端接口出高清成片 | 任务中心 |
| 发布 | 登记发布账号、链接、数据 | 发布记录 |

**两级出片机制（省钱关键）**：

1. **本地验证档**：公司 4090 显卡免费跑，2-7 分钟出一条预览片，用于先看效果、多方案对比
2. **云端高清档**：验证满意后再调云端接口出高清（768P / 2K），按秒计费（5 秒视频约几毛~1 元级），只在确定要用的素材上花钱

## 三、出片管线与评测模式（v1.1 新增）

| 管线 | 名称 | 原理 | 速度（5 秒素材参考） | 适合 |
| --- | --- | --- | --- | --- |
| A | 标准 | 25 步完整采样 | ~7 分钟 | 画质基准、高要求大片 |
| B | 快速 | 加速模型 turbo 8 步 | ~3 分钟 | 日常默认生产 |
| C | 智能 | turbo + 注意力加速 | ~2 分 40 秒 | 画质/速度平衡 |
| D | 极速 | 全加速组合 | ~2 分 10 秒 | 最快出片、批量试错 |

- 勾 1 条 = 日常生产；**勾 2-4 条 = 评测模式**：同素材同文案同时跑多条，出片后任务详情页并排对比 + 投票
- 投票规则：每人每批一票、可改投（以最后一次为准）；得票最高的管线即团队公认审美基准，后续同素材/同品类直接沿用
- 实测结论：多数素材 D（极速）画质接近 B（快速）但快 40%——先用评测模式验证，再固定常用管线

## 四、各模块操作要点

### 商品库（先有商品才能做视频）

- 必填：商品中文名；建议填全：负责人、类目、英文名、客单价、选品原因/卖点（**英文卖点会进视频文案**）、目标人群/市场、TikTok 参考链接
- 列表点「去制作」直跳制作台；「详情」看该商品的素材/脚本/制作记录

### 素材库（备料）

- 上传：产品图（≤9 张/任务）、爆款视频（mp4/mov ≤200MB、≥6 秒）、场景图/对比图/白底图/其他；视频自动生成封面
- **链接下载爆款（推荐）**：「⏬ 链接下载爆款视频」→ 贴 TikTok / YouTube 链接 → 可关联商品 → 后台几秒到几十秒自动完成

### 脚本库（把爆款「拆」成文字）

- 每个爆款存一份拆解脚本（运镜、动作、画面怎么走），同品类新品直接套用
- 类型分「正式脚本」「爆款拆解」；制作台选脚本后自动带入文案基础，可再改

### 制作台（核心操作）

四步引导：① 选商品 → ② 选脚本（可跳过）→ ③ 传素材 + 写文案 → ④ 选管线提交

- **爆款参考视频必传**（动作模板，AI 模仿其运镜和动作）；产品图选商品后自动带出，可补
- 生成文案：描述怎么把画面主体换成你的产品
- 确认后「🚀 提交制作」

### 任务中心（看出片 + 评测投票）

状态流转：验证中（4090 本地跑 2-7 分钟）→ 待确认（看预览片，满意出高清/不满意重做）→ 高清中（几分钟到几十分钟）→ 已完成（登记发布）／失败（看原因重做）

- 评测批次任务带「🔬 评测批次」标签，详情页顶部蓝色「🔬 评测批次对比」面板：并排预览 + 「🏆 此管线效果最佳」投票
- 出高清：待确认状态点「🌐 满意，出高清」，走云端 MiniMax H3 接口

### 发布记录

发布后登记：发布账号、时间、链接、浏览/点赞/评论/收藏/转发；汇总页用于复盘哪个品的视频数据好。

## 五、常见问题（FAQ）

| 问题 | 处理 |
| --- | --- |
| 提交时 ComfyUI 连接失败/提交失败 | 4090 在跑别的任务，等几分钟重试；长期不行找管理员 |
| 参考视频传不上 | 要求 mp4/mov、≤200MB、≥6 秒（做 5 秒视频需 ≥6 秒素材，10 秒需 ≥11 秒） |
| 产品图最多几张 | 每任务 ≤9 张，建议 1-4 张清晰、主体明确 |
| 出高清提示 API Key 未配置 | 云端密钥未配，找 admin 配置；本地验证档不受影响，可先评测囤片 |
| 管线选哪条 | 先评测模式（勾 B+C+D）跑一组投票定审美；多数素材 D 接近 B 且快 40% |

## 六、最佳实践

1. **素材质量 > 一切**：参考视频选动作清晰、单一主体、运镜稳定的爆款；产品图白底/干净背景
2. **批量评测**：同商品一次勾 2-3 条管线，投票定稿后固定管线批量生产
3. **先验证后高清**：高清按秒计费，永远先出本地验证片
4. **拆解沉淀**：好爆款存拆解脚本进脚本库，同品类复用
5. **数据闭环**：发布后及时登记数据，投流好的素材反向指导选品

## 七、与 creator-commerce-studio 的关系

自研的 [[creator-commerce-studio]] 项目立项时参考过本系统（2026-09-16 提示词存于该项目笔记）：

- **可借鉴**：提示词优化、出片管线（含多管线评测+投票）、生成视频/生成提示词/调用本地机器模型的打通
- **已识别缺点**（自研时要避免）：对用户操作理解不够傻瓜化、操作动线不合理、流程太长太复杂
- 自研系统流程尽量仿照 oumomo 的生成视频流程，而非照搬本系统
