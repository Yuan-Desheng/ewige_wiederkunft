## 一、核心机制

把要办的事写成一封邮件发给 **ai@jizhishida.com**（jizhishida.com 和 plantlove.com.cn 两个域名的邮箱都可以用），AI 团队几分钟内受理，做完在同一封邮件里把结果和文件回给你；不满意直接回邮件说，它接着改。

- 主题加标签（如 `[listing]`）分派更快，不加也行，分不清类别的自动进综合办公小队
- 一封邮件一件事，几件不相关的事分开发
- 附件单封邮件内原样转交处理人，单个 ≤ 25 MB，超了用网盘链接写正文
- 每人每天最多受理 10 件
- **它只看这封邮件和附件 + 公开互联网**，不会翻公司共享盘/飞书文档——内部数据不写进去，它就会回信问你，任务停在那等

## 三、任务邮件四要素

1. **主题**：一句话说清要什么，前面可加标签
2. **正文四要素**：
   - 背景：给谁用、哪个站点/语言、什么场景
   - 输入：产品参数、数据、政策数字（费率、时效、汇率、退换政策）写进邮件或放附件
   - 要求：想要几版、多长、什么口径
   - 交付格式：直接回信 / Excel / Word / PPT
3. **附件**：表格、截图、文档直接贴
4. **一封一件事**

## 四、发出之后会发生什么

| 时间 | 你会收到 |
| --- | --- |
| 几分钟内 | 「已受理，编号 WOR-xx」，写明它对任务的理解、交付物、验收标准、分到哪个小队。理解有偏差直接回信纠正 |
| 信息不够时 | 「需要你确认几个问题」，最多 3 个问题；7 天不回自动关闭 |
| 涉及资金/生产环境/对外发布/人事/合同，或工作量超两天 | 「需要 Terry 确认后才开工」，确认后在同一线程通知 |
| 做完 | 「WOR-xx 已完成」，结论在正文、文件在附件。小任务 5–10 分钟，大任务几小时 |
| 缺资料 | 「需要你补充信息」，回邮件补充（可带附件）自动继续 |

**原线程回复暗号**（必须在原邮件上点"回复"，新建邮件会被当成新任务）：

| 回复内容 | 效果 |
| --- | --- |
| 修改意见、补充要求（可带附件） | 同一个任务接着改，改完再回你 |
| 只写「进度」 | 立刻回复当前状态和最新进展 |
| 只写「取消」 | 撤销这个任务 |

## 五、边界（AI 团队不做的事）

- 不登录店铺后台、ERP、广告后台做操作（改价、上架、下单、调预算）；不付款、报销、签合同；不替公司给客户或达人发消息；不动生产环境；不做人事决定——这些它帮你把材料起草好，动作由人来做
- 处理人只部署到测试环境，上生产永远由人来做
- 邮件内容会进任务系统供处理人查看，**不要把密码、密钥写进邮件**
- 回信里的结论是 AI 员工产出，数字对外用之前自己复核一遍；估算和假设它会标出来
- 改两轮还不行，抄送 Terry（cuizhanwei@jizhishida.com）

## 六、提问邮件库（可直接改占位符后发送）

> 下面按小队整理了可以直接发的任务邮件草稿，`〈〉` 是占位符，发之前替换成真实数据。带 ★ 的是贴合 TK-SEA 选品上品工作台 / TikTok Shop 业务的。

### 6.1 运营小队

★ **批量 Listing 生成**（配合选品上品流程用）

```text
主题：[listing] 〈3 个新品〉马来站 TikTok Shop Listing 批量生成

正文：请为以下 3 个产品各写一套 TikTok Shop 马来站（马来语+英文双语标题）Listing：
英文标题 2 版、5 条卖点、描述、属性表、关键词四组。
产品事实见附件参数表（面料/颜色/尺码/重量都已在表内）。
交付：一个 Excel（每个产品一个 sheet，含标题/卖点/描述/属性/关键词分栏）+ 回信直接贴第一个产品的标题和卖点。
```
素材：产品参数表（品名、面料成分、颜色、尺码表 cm、重量、卖点事实）

★ **选品评分**

```text
主题：[选品] 〈类目，如"女士瑜伽服配件"〉本月选品评分

正文：附件是 〈20〉 个候选品的参数表（1688 采购价、重量、竞品售价、月销量估算）。
请按我们之前的评分口径（市场容量/竞争度/利润率/物流友好度）打分排序，输出评分表和前 5 名的一句话理由。
评分权重若有疑问，按 利润率 40%、市场容量 30%、竞争度 20%、物流 10% 来。
交付：Excel（原始数据+评分两 sheet）+ 回信贴前 5 名表格。
```
素材：候选品参数表 CSV、评分权重（如已固定口径则写"按上次口径"）

**广告数据复盘**

```text
主题：[投流] 〈9 月〉〈新加坡站〉广告投放数据复盘

正文：附件是 〈9 月〉广告后台导出的 CSV（按广告组/按天两个 sheet）。
请：1) 按 SKU 汇总花费、GMV、ROI、ACOS；2) 找出 ROI < 1 且花费超 〈$100〉 的广告组，给出关停/降预算/换素材建议；3) 按 7 天趋势出花费与 ROI 折线数据表。
交付：Excel（原始/按 SKU/建议 三 sheet）+ 回信贴建议清单。
```
素材：广告后台导出 CSV、花费阈值口径

## 七、发信前素材准备清单

> 核心原则：**它只看你的邮件和附件，不会去翻公司共享盘**。没给的内部数据它会停下来问你。

| 素材类型 | 具体内容 | 常用任务 |
| --- | --- | --- |
| 产品参数表 | 品名、面料成分、颜色、尺码表（cm）、重量、卖点事实 | listing、内容、达人 |
| 销量库存数据 | SKU、近 30 天销量、当前库存 | 备货、补货 |
| 供应链参数 | 采购交期、头程时效、缓冲天数、目标仓 | 备货、物流 |
| 政策数字 | 平台费率、汇率口径、退换政策、佣金比例 | 投流、财务、达人 |
| 后台导出文件 | 结算 CSV、广告报表、销售报表（可脱敏） | 数据、财务、投流 |
| 口径说明 | 评分权重、花费阈值、币种折算规则 | 选品、投流、数据 |
| 截图 | 竞品页面、系统界面、1688 链接截图 | 采购、需求、调研 |

注意：
- 附件里的敏感字段（真实成本价、供应商全名、内部价格）发给 AI 邮箱前自己权衡；**密码、密钥绝对不能出现在邮件任何位置**
- 附件超 25 MB 用网盘链接 + 提取码写正文
