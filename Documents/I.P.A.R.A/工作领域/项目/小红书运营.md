#### 6. 升级图片风格：v2 → v3 三维匹配

你提了：**图片应该根据文案情绪、人群、平台选不同的视觉语言**。这是 v2 通用模板没解决的：

- v2 全是「Kodak Portra 400 / 35mm / 浅景深」一套，对「治愈」「反思」「兴奋」类文案力度不够
- 没区分人群：独立开发者的深夜工位、CTO 的团队 standup、客服的工作台完全不是一个画风
- 没区分平台：小红书 3:4、飞书群图 1:1、公众号 16:9 构图约束不同

**v3 设计**（6 情绪 × 5 人群 + 平台 = 90 种组合，实际展开 30 组合）：

- 6 类情绪各配专属胶片 + 色调 + 光
- 治愈和反思类默认只出 2 张图（避免用力过猛）
- 平台只影响 prompt 末尾的构图词

**分类协议**：hermes 在步骤 2 出文案时同步分类，写到 `<NN>-meta.json`：

```json
{
  "nn": "01",
  "topic": "...",
  "title": "...",
  "mood": "...",
  "audience": "...",
  "platform": "小红书",
  "image_count": 2,
  "rationale": "...",
  "body_chars": 720
}
```

拿不准 → 默认 `{mood: 沉稳, audience: 独立开发者, platform: 小红书}`。

#### 8. 体感反馈 → v3.1 修订

你看了 10 条后反馈：**太多黑白色**。

**根因**：v3 给「沉稳」和「反思」配的是 Ilford HP5 Plus 黑白胶片，这两个情绪合计 7 篇（60%），所以群里黑白占主导。

**v3.1 修订**（去黑白）：

| 情绪 | 旧（v3 初版）| 新（v3.1）|
|---|---|---|
| 沉稳 | Ilford HP5 黑白 | **Kodak Portra 400 低饱和淡彩** |
| 反思 | Fuji Classic Negative 复古绿黄 | **Fuji Pro 400H 暖白柔肤** |

外加：反向规则新增禁用 `black and white / Ilford HP5 / B&W / monochrome`。

#### 9. 体感反馈 → v3.2 修订

你又看了之后反馈：**希望暖色系多一些**。

**v3.2 修订**（偏好暖色）：

| 情绪 | 旧（v3.1）| 新（v3.2）|
|---|---|---|
| 焦虑 | Cinestill 800T 蓝橙冲 | 保留（橙是暖色，整体仍偏暖）|
| 治愈 | Fuji Pro 400H 暖白 | 不变 |
| 反差 | Portra 400 **冷暖分屏（金+蓝）** | **暖分屏（金+米白）** |
| 兴奋 | Ektar 100 鲜亮 | **金黄暖调 + 黄金时刻加强** |
| 沉稳 | Portra 400 **偏冷灰淡彩** | **米黄+琥珀暖版** |
| 反思 | Fuji Pro 400H 暖白 | 不变 |

**v3.2 触发优先级**（多个候选 mood 时，**优先暖色那个**）：
治愈 > 反思 > 兴奋 > 沉稳 > 反差 > 焦虑

**预期效果**：6 类情绪全部偏暖，暖色系覆盖率从 v3.1 约 50% → v3.2 接近 100%。

#### 10. 复盘教训

1. **「我做了一次实测」不等于「结论正确」**。那次实测只看了 `/v1/models`，没意识到 MiniMax 还有自家多模态 endpoint。下次遇到「X 没有 Y」类结论，至少再扫一眼官方文档
2. **拍脑袋的「安全值」要标注存疑**。4 KB 安全上限我定的很随意，删的时候要解释为什么
3. **并行 hermes 会话会改 SKILL.md**。今天几次 patch 被打断都是外部 hermes 改的。养成 patch 前先 `read_file` 重新读取的习惯
4. **「风格单一」是体感问题，不是技术问题**。黑白胶片技术上完美，但用户视角看就是单调。下次出图前考虑视觉比例分布（暖冷 / 黑白彩 / 强弱对比）
