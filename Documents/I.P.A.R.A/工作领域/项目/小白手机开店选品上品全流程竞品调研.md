## 一、对照锚点：TK-SEA 现在是什么

[[tk-sea-seller]] 是给**已经有 TikTok Shop 东南亚跨境店**的团队操作员用的桌面流水线，不是给路边小白用的手机副业 App。

| 环节 | 已经做成的 |
|---|---|
| 选品 | FastMoss 跨境店新品榜 / 热推榜，或贴 `shop.tiktok.com` 商品链接；公司商品库去重 |
| 货源 | 商品图在 1688 图搜，抽取价格、重量、尺寸、SKU |
| 核价 | 云端 decimal，按东南亚多国费率算出控利润成交价和前台挂牌价，和竞品价对比后保留 / 待补充 / 淘汰 |
| 采集上品 | 本机专用 Chrome 驱动妙手 ERP 链接采集、校正目标店、填价、发布 |
| 发布后 | Seller Center 多国改价改库存，写台账 |
| 协作 | Casdoor 多租户、任务看板、人工闸门（登录验证码、发布前复核由人点确认） |

技术形态：操作员电脑上的 Electron + 本机专用 Chrome；云端只做登录、核价、多租户数据。系统不收集各平台账号密码。明确不做开店、不做手机端、不代用户跟平台客服或 1688 供应商说话。

它已经做到的深度，是市面铺货 ERP 很少接上的那一段：**算得清能不能卖，再决定上不上，上完回读确认。** 和「小白闲暇手机全流程」是两类产品。给工作台套一个手机壳，采集、填价、发布仍然过不了——这些步骤绑在本机 Chrome 和已登录的妙手 / 商家中心上。

## 二、调研问题怎么拆

同时满足下面五项，才算「就是那个产品」：

1. 面向 0 基础、没有跨境 / 电商经验的个人
2. 闲暇时间可用（每天大约 30–90 分钟）
3. 主要在手机上完成（原生 App / 小程序 / 手机浏览器）
4. 覆盖开店、选品、上品三段，而不是只覆盖其中一段
5. 目标优先 TikTok Shop（东南亚跨境、美区 / 英区、全托管 / 半托管 / POP），同时看其他平台

三段的含义：

- **开店**：协助完成平台入驻（资质、主体、保证金、收款、仓库 / 物流绑定），不是已经有店之后的管店
- **选品**：告诉用户卖什么、从哪进货、能不能赚钱
- **上品**：把商品真正发布到目标店铺并进入可售状态（类目、图文、规格、价格、库存、合规）

## 三、市面上接近的东西（按接近度）

接近度按「有多像那五项同时成立」排，不是按公司大小或功能多少排。每一条写清：它实际覆盖哪几步、缺哪几步、谁在用、官网和下载入口。

### 接近度 1｜国内手机原生开店（形态最像，平台不是跨境 TK）

这是检索里**唯一真正能在手机上从开店走到上架、收单**的形态。闲暇碎片时间、0 基础个人，走的是这一路。履约是国内快递，合规是国内主体，利润模型和 TikTok 东南亚跨境店不是同一件事。

| 产品 | 做什么 | 开店 | 选品 | 上品 | 形态 | 官网 / 下载 |
|---|---|---|---|---|---|---|
| **闲鱼** | 个人闲置和个人卖家，手机拍照上架 | 手机内完成实名即可卖 | 自己找货 | 手机上架 | 原生 App | 官网 [goofish.com](https://www.goofish.com/)；应用商店搜「闲鱼」 |
| **微店** | 个人 / 小店手机开店，微信里卖 | 手机注册开店 | 自己找货或供货市场 | 手机上架 | 原生 App + H5 | [weidian.com](https://www.weidian.com/)；应用商店搜「微店」 |
| **抖店（抖音电商商家）** | 抖音小店经营：上架、订单、达人 | 主体入驻多在电脑商家后台；日常管店有 App | 平台推荐 + 自己选 | 电脑为主，App 可补 | PC 商家后台 + 商家 App | 商家后台 [fxg.jinritemai.com](https://fxg.jinritemai.com/)；应用商店搜「抖店」 |
| **快手小店** | 快手电商商家经营 | 入驻走电脑 / App 申请 | 自己选 | 电脑 + 商家 App | PC + App | 商家后台 [s.kwaixiaodian.com](https://s.kwaixiaodian.com/)；应用商店搜「快手电商商家版」 |
| **视频号小店** | 微信视频号挂店卖货 | 微信内申请，需主体 | 自己选 | 微信内 + 电脑 | 小程序 / 电脑 | [store.weixin.qq.com](https://store.weixin.qq.com/) |
| **拼多多商家** | 国内平台开店、上架、订单 | 入驻走商家后台 | 自己选 | 电脑批量 + 商家 App | PC + App | [mms.pinduoduo.com](https://mms.pinduoduo.com/)；应用商店搜「拼多多商家版」 |
| **有赞** | 微信生态开店 SaaS，偏本地生活和私域 | 注册即可建店，支付 / 资质另走 | 自己选 | 电脑 + App | SaaS + App | [youzan.com](https://www.youzan.com/) |

对 TK-SEA 的启发：如果以后要做「闲暇小白 + 纯手机」，国内这一侧才有现成用户习惯可抄；跨境 TK 抄不来这条路径。

### 接近度 2｜海外一件代发 / AI 建店（叙事最像「小白从零卖货」）

英文市场把「不会电商的人、从零开店、一键上架、出单后代发」讲得很完整。主体是 Web，开店审核、税号、物流模板仍要人在 TikTok Seller Center 里做完。内容带货（短视频 / 达人 / 直播）这些产品包不了。

#### AutoDS

一件代发中台：接 Shopify、eBay、Amazon、Etsy、Facebook、TikTok Shop 等，从供应商目录或链接导入商品，AI 生成标题描述，推到店铺，出单后向供应商下单并回写运单。另有新手课。

- 覆盖：选品目录、刊登、履约自动化
- 缺口：TikTok 入驻、保证金、税表、仓库地址仍在官方后台；默认是电脑浏览器
- 用户：准备做 dropshipping 的个人和小型店主，英文为主
- 官网：[autods.com](https://www.autods.com/)
- TikTok Shop 专题：[autods.com/blog/tiktok-dropshipping](https://www.autods.com/blog/tiktok-dropshipping/)
- 课程：[autods.com/courses/tiktok-dropshipping-course](https://www.autods.com/courses/tiktok-dropshipping-course/)

#### Build Your Store AI（AutoDS 同一公司）

宣传「选一个类目，几分钟生成 Shopify 店 + 起始商品 + 一年免费域名」，流程可以在手机浏览器走完。生成的是独立站，不是 TikTok Shop。店建好后再装 AutoDS 进货。

- 覆盖：独立站开店的「外观和货架」
- 缺口：平台店铺入驻、核价、TK 发布、履约考核
- 官网：[buildyourstore.ai](https://www.buildyourstore.ai/)

#### Doba

老牌一件代发，货盘偏美国仓现货，可推到 Amazon、eBay、Shopify、TikTok Shop。2025 年后上了 AI Pickr 选品和 AI 生成标题图文。

- 覆盖：选品、一键刊登、库存同步、出单采购
- 缺口：先有店；开店、内容、跨境直邮核价不在产品里
- 官网：[doba.com](https://www.doba.com/)
- 刊登教程：[doba.com/blog](https://www.doba.com/blog/) 内 TikTok Shop listing 指南

#### CJDropshipping

货盘 + 代发履约，可把选中商品推到 TikTok Shop / Shopify，订单自动给 CJ 履约。无月费，靠货品差价。有美国、英国、欧盟、中国仓。

- 覆盖：选品浏览、推品到店、履约
- 缺口：开店；美区对自发货 / TikTok Shipping 政策在变，代发时效要单独核对
- 官网：[cjdropshipping.com](https://cjdropshipping.com/)

#### Zendrop / Spocket

偏 Shopify 一件代发。Zendrop 强调美国仓和品牌定制包装；Spocket 强调欧美供应商、较短时效。TikTok Shop 是后接渠道，不是主场。

- Zendrop：[zendrop.com](https://www.zendrop.com/)
- Spocket：[spocket.co](https://www.spocket.co/)

### 接近度 3｜「选品 + 开店材料」工具（宣传 0 基础，执行上品在店外）

#### 就要出海

重庆鑫梦源的 AI 选品工具。宣传 30 分钟上手：一键出蓝海 SKU、查侵权 / 违规、匹配货源、测算利润，并附店铺审核材料和申诉、社群指导。

- 覆盖：选品决策、货源线索、开店材料清单
- 缺口：不代替平台审核，不把商品发布进 TikTok / Shopee 店铺
- 用户：想入局的个人，付季付 / 半年付 / 年费
- 官网：[jiuyaoch.com/mh](https://jiuyaoch.com/mh)
- 第三方介绍：[tbadc.com 词条](https://www.tbadc.com/hao/jiuyaoch.html)

这一档最容易被文案写成「一站式」，实际是选品 SaaS + 人工陪跑。和 TK-SEA 的「已有店、真发布、回读确认」不在一层。

### 接近度 4｜官方卖家 App（手机有，全流程没有）

官方把「已经开好的店」搬到手机上：看订单、改部分商品、回消息、看数据。入驻资料、保证金、仓库、税务，官方自己也写「店铺设置阶段 PC 更方便」。App 里上品是手工填表，没有 1688 货源，没有多国费率核价。

#### TikTok Shop Seller Center（官方商家 App）

TikTok Pte. Ltd. 出品。Google Play 公开资料约 5000 万+ 安装（2026-10 AppBrain 计约 5300 万）。文案写 Register and set up your store、Add products，实际入驻重资料仍走电脑 Seller Center。

- 覆盖：有店之后的手机管店、手工上品、订单售后
- 缺口：选品、货源、核价、批量采集、开店资质办理
- Google Play：[TikTok Shop Seller Center](https://play.google.com/store/apps/details?id=com.tiktokshop.seller)（包名 `com.tiktokshop.seller`）
- App Store：[TikTok Shop Seller Center](https://apps.apple.com/us/app/tiktok-shop-seller-center/id1591003012)（App ID `1591003012`）
- 美区电脑后台：[seller-us.tiktok.com](https://seller-us.tiktok.com/)
- 大学说明（App 上品）：[Add products via Seller Center App](https://seller-us.tiktok.com/university/essay?knowledge_id=428445524264746)

#### 跨境 POP 商家中心 App

面向中国跨境 POP 商家的官方移动管店。支持美区、欧盟、英国、东南亚、墨西哥；**需店铺设置完成、进入正常经营**后使用。下载常要非中国区商店账号。和上面 Seller Center 是同一产品线、同一包名，入口文案不同。

- 覆盖：跨境 POP 日常管店
- 缺口：开店设置、选品、货源核价
- 电脑入驻 / 经营：[tiktokshopglobalselling.com](https://www.tiktokshopglobalselling.com/)
- 跨境卖家后台：[seller.tiktokshopglobalselling.com](https://seller.tiktokshopglobalselling.com/)
- 下载：海外 Google Play / App Store 搜「TikTok Shop Seller Center」（同上两条商店链接）

买家侧的「TikTok Shop」购物入口在 TikTok 主 App 里，不要和卖家 App 混成一个产品：[shop.tiktok.com/us/tiktok-app](https://shop.tiktok.com/us/tiktok-app)

### 接近度 5｜跨境铺货 ERP（上品强，开店 / 手机 / 小白弱）

能力是：店已经开好并授权之后，从 1688 / TikTok / 淘宝采集，翻译，批量刊登，处理订单采购。主体是电脑浏览器或插件。文案里的「小白」指「第一次用 ERP 的卖家」，不是「第一次做生意的路人」。TK-SEA 的采集发布已经走妙手这一层。

#### 妙手 ERP（TK-SEA 已接入）

深圳呈云。采集 100+ 货源站、多平台刊登、定价模板、订单仓储物流。公开报价低至约 4.5 元 / 店铺 / 月。宣称 110 万+ 跨境卖家。有 TikTok Shop 全托管授权、开店绿色通道（通道是材料导流，审核仍在平台）。

- 官网：[erp.91miaoshou.com](https://erp.91miaoshou.com/)
- 品牌站（国内版另开）：[91miaoshou.com](https://www.91miaoshou.com/)
- 开店通道：[erp.91miaoshou.com/platforms.html](https://erp.91miaoshou.com/platforms.html)
- 登录后采集箱（团队在用）：`https://erp.91miaoshou.com/common_collect_box/index`

#### 店小秘 ERP

深圳美云集。铺货采集刊登见长，基础版可免费起步。对接 Temu、TikTok Shop、速卖通、Amazon、Ozon、Shopee 等 70 余平台。TikTok 商机品 + 热卖榜可在系统内看。官方说没有独立 App，手机用浏览器打开官网。有微信服务号 PDA 打单。

- 官网：[dianxiaomi.com](https://www.dianxiaomi.com/)
- 帮助中心：[help.dianxiaomi.com](https://help.dianxiaomi.com/)

### 接近度 6｜选品数据（只告诉你卖什么）

看榜、看达人、看直播、看广告素材。手机 H5 / 小程序能刷榜。不上架，不算利润（或只做粗算），不开店。TK-SEA 的选品源已经接 FastMoss。

#### FastMoss

TikTok Shop 数据：新品榜、热推榜、商品 / 达人 / 直播 / 店铺。有电脑、手机 H5、小程序。TK-SEA 批量上品扫的就是跨境店新品榜和热推榜。

- 官网：[fastmoss.com](https://www.fastmoss.com/)
- 跨境店新品榜（团队常用）：[fastmoss.com/zh/e-commerce/newProducts](https://www.fastmoss.com/zh/e-commerce/newProducts)

#### Kalodata

TikTok Shop 数据分析，覆盖约 15 个站点，另有 Amazon / Shopee 数据。电脑 + 手机 Web + iOS / Android App。7 天试用。

- 中文站：[kalodata.com/zh](https://www.kalodata.com/zh)
- 英文站：[kalodata.com](https://www.kalodata.com/)

## 四、若硬凑一套「小白路径」，实际是拼盘

现有卖家已经在用的组合：

```text
营业执照代办
  → 官方入驻（电脑 Seller Center / 全托管后台）
  → FastMoss / Kalodata / EchoTik 选品（手机能看榜）
  → 1688 找货（电脑或手机 App）
  → 妙手 / 店小秘 / 客优云 / AutoDS 上品（电脑）
  → Seller Center App 管订单（手机）
  → 连连 / 万里汇收款
```

这是工具箱，不是一个产品，也不是 0 基础闲暇路径。每段都要单独登录、单独付费、单独扛审核和履约。

## 五、结构性卡点

| # | 卡点 | 2026-10 判断 |
|---|---|---|
| 1 | 开店资质：执照、法人、保证金、对公 / 连连、发货仓 | 软件可做材料清单和进度；审核在平台。官方 App 把店铺设置留在 PC |
| 2 | 跨境上品字段多、失败贵：类目属性、多规格、重量尺寸、多国价、合规、驳回 | TK-SEA 用 dry-run + 写后回读，因为「接口说成功」和「页面真写上」经常不是一回事。手机一键搬，驳回成本在卖家 |
| 3 | 选品和核价是分开卖的 | FastMoss 不管上架；妙手不管「按五国费率能不能留目标净利」。TK-SEA 的差异化正在把这两段接上 |
| 4 | TikTok 是内容电商 | 货上了架，没有短视频、达人或直播，等于没进入分发。纯上品工具解决不了「闲暇也能出单」 |
| 5 | 履约有考核 | 一件代发晚发、全托管到仓超时、售后差评打店铺分。碎片时间很难稳定履约 |
| 6 | 合规 | 登录人工、不收集平台密码、不代发外部消息——这是 TK-SEA 已定的红线，也是正规产品能卖的边界 |

## 六、和现有项目的关系

加一个手机端，做不成「0 基础闲暇全流程」这个故事。用户、平台动作、履约、收费都要换。现有资产里能复用的，主要是：**核价内核、选品闸门、任务状态机、人工确认设计**。浏览器自动化和 Electron 壳带不过去。

若以后要碰「更小白、更移动」，三个比较现实的切口：

1. **工作台的手机配套：只做看和批。** 操作员出门时看卡在哪一步、点「确认复核」。采集发布仍在办公室电脑。这是现有产品的下一端，用户还是团队运营。
2. **国内手机平台 MVP。** 闲鱼 / 视频号 / 抖音小店：开店上品本来就在手机上。用「货源 + 核价 + 清单式引导」降低小白决策成本。和 TK 东南亚不是同一个市场。
3. **有货商家的全托管推款助手。** 用户是工厂 / 档口。手机上看爆品、算供货价、看推款进度。开店和入仓仍走官方。

「0 基础 + 纯手机 + 跨境 TK 开店选品上品」更适合当宣传句，不适合当 12 个月的产品范围。现有工作台的护城河仍是：已有店的团队，把选品、核价、采集、发布收成一条算得清、回得了读的流水线。
