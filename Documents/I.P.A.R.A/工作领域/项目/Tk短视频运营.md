**流程说明注解****[****执行标准和输出****]**

**流程****01** **明确视频目标**

1. 动作：确定本批视频唯一目标：拉播放 / 拉互动 / 拉转化 / 测试新形式
    

2. 判断：一条视频只能一个目标
    

3. 输出：视频任务方向表
    

**流程****02** **建立关键词池**

1. 动作：建立三类关键词：大类目关键词/产品词 / 内容词 / 情绪词/
    

2. 方法：每个维度至少10个关键词
    

3. 输出：关键词池
    

**流程****03** **搜索爆款视频**

1. 动作：使用关键词在平台搜索视频
    

2. 方法：关键词 → 视频 → 作者
    

3. 筛选标准：播放高 / 点赞率高 / 评论活跃 / 结构清晰 / 场景可复刻
    

4. 数量：每关键词至少看20条视频
    

5. 输出：初筛视频清单
    

**流程****04** **筛选可复制视频**

1. 动作：逐条判断可复制性
    

2. 判断条件：
    

前3秒是否有钩子

动作是否可复制

场景是否可还原

是否可替换产品

1. 规则：满足4条入库，否则淘汰
    

2. 输出：对标视频池
    

**流程****05** **建立对标视频库**

1. 动作：录入视频库
    

2. 记录字段：
    

3. 视频链接 / 账号名称 / 发布时间 / 播放量 / 点赞量 / 评论量 / 视频类型 / 核心爆点
    

4. 输出：对标视频库
    

**流程****06** **视频分类**

1. 动作：给视频打标签
    

2. 类型：
    

3. 流量型 / 种草型 / 转化型 / 互动型
    

4. 输出：分类标签
    

**流程****07** **拆解黄金****3****秒**

1. 动作：逐秒拆解
    

2. 0-1秒：画面
    

3. 1-2秒：动作
    

4. 2-3秒：字幕或冲突
    

5. 输出：前3秒拆解表
    

**流程****08** **拆解视频结构**

动作：拆成四段

开头钩子

中段强化

高潮镜头

结尾收口

输出：结构拆解表

**流程****09** **拆镜头动作字幕卖点**

拆解6个维度：镜头 / 景别 / 动作 / 字幕 / 卖点 / 转化点

  
  

示例：

镜头：远景、中景、特写

动作：猫闻、猫跑、猫吃

字幕：My cats love this

卖点：猫非常喜欢吃

转化：产品露出

输出：标准拆解表

**流程****10** **提炼可复制点**

动作：总结

可复制点 / 不可复制点

规则：

保留结构

替换产品

删除高成本元素

输出：可复制爆点清单

**流程****11** **改写仿拍脚本**

脚本必须包含：

开头画面

镜头顺序

字幕文案

产品露出

结尾互动

输出：仿拍脚本单

**流程****12** **拍摄剪辑**

拍摄顺序：

先拍前3秒

再拍核心爆点

最后补拍特写

关键镜头拍2-3版

剪辑流程：

粗剪结构 → 精剪节奏 → 加字幕 → 加音乐

输出：视频成片

**流程****13** **发布**

记录信息：发布时间 / 标题 / 标签 / 封面

输出：发布记录

**流程****14** **数据复盘**

观察指标：

播放量 / 3秒停留 / 完播率 / 点赞率 / 评论率 / 转化率

对比：原对标视频 vs 自己视频

输出：复盘结论

**流程****15** **更新对标库**

动作：更新标签

适合复制 / 不适合复制

周期：每周更新一次

输出：迭代后的对标库
