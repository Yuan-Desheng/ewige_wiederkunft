#### 样式优化经验总结

**已验证的有效方案：**

1. **步骤编号**：不要用 "Step 1" 英文格式，改用蓝色圆形徽章（OVAL + 数字）+ 中文说明文字，每步独立 `addText` 定位，避免富文本换行问题
2. **行间距控制**：不依赖 `paraSpaceAfter` / `paraSpaceBefore`，改用 y 坐标精确定位每行文字高度（0.38-0.42 英寸）
3. **图片比例**：不要用 `sizing: { type: 'contain' }` 参数（对极端宽高比图片不可靠），改为手动计算：
   - 读取 PNG 文件头获取实际像素尺寸（`fs.readFileSync` + `readUInt32BE`）
   - `fitInBox(imageNum, boxX, boxY, boxW, boxH)` 计算等比缩放后的精确 w/h，居中定位
   - `addImage` 只传计算好的 x/y/w/h，不传 `sizing`

**关键代码片段（图片等比缩放）：**
```javascript
function readPngSize(filePath) {
  const buf = fs.readFileSync(filePath);
  if (buf[0] === 0x89 && buf[1] === 0x50 && buf[2] === 0x4E && buf[3] === 0x47) {
    return { w: buf.readUInt32BE(16), h: buf.readUInt32BE(20) };
  }
  return null;
}

function fitInBox(imageNum, boxX, boxY, boxW, boxH) {
  const sz = readPngSize(img(imageNum));
  if (!sz) return { x: boxX, y: boxY, w: boxW, h: boxH };
  const imgRatio = sz.w / sz.h;
  const boxRatio = boxW / boxH;
  let dispW, dispH;
  if (imgRatio > boxRatio) { dispW = boxW; dispH = boxW / imgRatio; }
  else { dispH = boxH; dispW = boxH * imgRatio; }
  return { x: boxX + (boxW - dispW) / 2, y: boxY + (boxH - dispH) / 2, w: dispW, h: dispH };
}
```
