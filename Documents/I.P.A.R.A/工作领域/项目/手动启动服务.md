# 手动启动服务

以下服务已从开机启动中移除，需要时手动启动。

## ChatDev 2.0

**路径：** `/home/yuan/ChatDev`

**启动命令：**
```bash
/home/yuan/ChatDev/start.sh
```

**停止命令：**
```bash
kill $(cat /home/yuan/ChatDev/pids/backend.pid) $(cat /home/yuan/ChatDev/pids/frontend.pid)
```

**访问地址：**
- 前端：http://localhost:5173
- 后端：http://localhost:6400

**日志位置：**
- 后端：`/home/yuan/ChatDev/logs/backend.log`
- 前端：`/home/yuan/ChatDev/logs/frontend.log`
