## 0. 一分钟版

```
Seerfar → 功能 → 选品 → 市场热词选品 (market.html)
  → 填筛选条件（月搜热度 / 月搜增长 / 竞品数）
  → 点「查询」
  → 右侧「导出」→ 选 XLSX → 填条数 → 导出
```

**唯一要记住的坑：导出每次最多 2000 条。** 超过就得改筛选条件分批导，然后自己拼——`7月6日关键词xlsx.xlsx` 就是这么来的（2000 + 1843）。

**别停在导出。** 站上只能筛热度/增长/竞品数，跨境能不能发它一概不管。导完必须在本地再筛四条
（退货取消率 / 重量 / 体积 / 价值密度，见 **§2.2**），否则表里全是洗衣机和桦木柴。

**如果你要找的是 `_改.xlsx` 那份 589 行的**：它跟上面的流程无关，是导完之后在 WPS 里筛的（`退货取消率 < 10%`）→ 直接看 **§6**。

## 2. 填筛选条件

完整口径是**两段**：站上能填的 3 条 + 导出后在本地再筛的 4 条。**只做第一段会留下一堆跨境根本发不了的货。**

### 2.1 站上填的三个条件

| 条件 | 值 | 为什么 |
|---|---|---|
| **月搜热度** 最小值 | `5000` | 需求门槛，滤掉没人搜的长尾 |
| **月搜增长** 最小值 | `0` | 排除正在衰退的词 |
| **竞品数** 最大值 | `500` | **蓝海的核心条件**，竞争稀薄 |

![[Seerfar关键词导出-02-填好筛选条件.png]]

> 注意「竞品数」填的是**最大值**那一格（右边），不是最小值。三个框的位置：月搜热度在中列上、月搜增长在中列下、竞品数在右列上。

### 2.2 🔴 导出后必须在本地再筛的四条

这四项**精简模式的筛选区里没有**（进阶模式没验证），但所需字段**导出的 21 列里全都现成**，用 Excel 筛一遍就行：

| 条件 | 阈值 | 用哪列 | 砍掉什么 |
|---|---|---|---|
| **退货取消率** | `< 10%` | 现成第 21 列 | 3C / 服饰这类高退货品类。**唯一能整体筛掉智能手机的一刀**（140→4） |
| **重量** | `≤ 2000 g` | 现成第 19 列 | 洗衣机 67kg、椭圆机 62.9kg —— 小包发不了 |
| **体积** | `≤ 10 L` | 现成第 20 列 | 冰柜 519L、除雪机 259L |
| **价值密度** | `≥ 0.5 ₽/g` | **要自己算** `=平均价格 ÷ 重量` | 低价重货：蒸馏水 `0.072`、25kg 工业盐 `0.112`、桦木柴 `0.126` —— 头程运费吃光利润，**这类只在俄本地卖** |

**在 1460 行上跑一遍的漏斗**（每步累加）：

```
1460  原始（蓝海口径 + 只保留跨境可售）
 590  ① 退货取消率 < 10%      ← 空值 7 行保留
 498  ② + 重量 ≤ 2000 g
 490  ③ + 体积 ≤ 10 L
 442  ④ + 价值密度 ≥ 0.5 ₽/g
```

留下 442 行，重量 max `1980g`、体积 max `8.7L`、价值密度 min `0.51 ₽/g`。
② 单独用留 498、③ 单独留 551、④ 单独留 475 —— **四条互相不能替代，②③④ 尤其别只挑一条**。

> ⚠️ 重量/体积各有 2 行为空。上面按「通过」处理，但**结果一样是 442** —— 因为算不出价值密度的行在 ④ 就被筛掉了。
> 📌 **为什么必须做 ②③④**：`退货取消率` 完全不管物流。大家电退货率低只是因为没人随手退，不代表能跨境发。详见 §6.3 ④。

### 2.3 口径怎么选

实测过五套，条数差别很大（**未撞 5000 上限才是完整集合**）：

| 口径 | 条件 | 命中 |
|---|---|---|
| 官方「潜力市场」 | 月搜增长 ≥ 10% | ≥5000 ⚠️ 撞顶，等于没筛 |
| 复刻旧口径 | 月搜增长 ≥ 1% | ≥5000 ⚠️ 撞顶 |
| **均衡（本次采用）** | 月搜热度≥5000 + 竞品数≤500 + 增长≥0 | **1709** |
| 宽 | 月搜热度≥2000 + 竞品数≤1000 + 增长≥30% | 4132 |
| 严选 | 月搜热度≥10000 + 竞品数≤300 + 增长≥20% | 81 |

**结论：只筛「增长」没用，真正起作用的是竞品数上限。** 这也解释了旧文件为什么要导两次——条件太松，2000 行装不下。

### 4.3 🔴 2000 条上限

「导出」右边那个 `?` 的提示原文（取自站点语言包）：

```
export_max_amount_tips = 当前支持的最大导出数据为2000条
export_amount_choose   = 导出列表前 [200] 条数据
```

所以：

- 单次导出**最多 2000 条**，填再大也没用
- 命中 1709 条 → 一次导完 ✅
- 命中 4132 条 → 得改筛选条件拆成两批，或者接受只拿前 2000

**这就是 `7月6日关键词xlsx.xlsx` 有 3843 行的原因**：两次导出（2000 + 1843）拼起来的。证据在文件里——`排名` 列有 1846 个值出现了两次、151 个出现一次，因为 `排名` 是**每次导出内部的序号 1..2000**，不是全站排名。拼接后又重新排过序，所以打开看到的 `排名` 是乱的（379、736、1530…）。

## 6. `_改.xlsx` 是怎么来的（二次加工版，2026-07-27）

`Seerfar蓝海词_均衡_20260727_改.xlsx`（589 行 × 22 列）**不是又导了一次**，是把上面那份 1460 行在 **WPS** 里加工出来的。
Seerfar 侧没有任何对应操作——不用去站上重查。

> 取证：WPS 12.1.0.26895 另存，`lastModifiedBy=清心`，改动时间 2026-07-27 16:48（北京）。
> 589 行 × 20 个数据列共 11780 个单元格与「原」**逐格零差异**（含浮点逐位相等），所以是同一份数据快照。

### 6.1 五步复原（已逐行验证，589 行的顺序和排名 100% 吻合）

| 步   | 操作                                                                | 结果      |
| --- | ----------------------------------------------------------------- | ------- |
| ①   | 取「原」1460 行（已按 月搜热度 降序，排名 1..1460）                                 | 1460    |
| ②   | 在 H(销售额) 后插一列，表头也叫 **「市场空间」**，填公式 `=J{r}/L{r}`（**月搜热度 ÷ 商品数**）    | 22 列    |
| ③   | 按这列排序：商品数为空 → `#DIV/0!` 的 **654 行排最前**（组内保持原月搜热度降序），其余 806 行按数值降序 | 重排      |
| ④   | 「排名」列按新顺序重编号 1..1460（仍是文本）                                        | —       |
| ⑤   | 筛掉 **退货取消率 ≥ 10%**（空值 7 行保留）→ 590；再删 1 行 `туалета`                | **589** |

> 📌 **为什么要在 ② 里专门插一列算「市场空间」？** 想用一个数同时反映「搜的人多」和「卖的少」——单看月搜热度会撞红海、单看竞品数会撞死词，相除才得到「供需缝隙度」。动机与两个口径的取舍见 **§6.5**；但这列用的是 ÷商品数 口径、42.8% 算不出来，排序不可信，坑见 §6.3 ②③。

**筛选口径就一条：退货取消率 < 10%。** 边界是严格小于——正好 `10.00%` 的 `экдистерон`（原排名 157）被剔掉了；
保留组最大 9.99%，剔除组次低 10.01%。退货取消率为空的 7 行**被保留**（复现时注意，用 Excel「小于」筛选会把空值一起筛掉，就少 7 行）。

> **多删的那 1 行 `туалета`（猫砂）是人工判断，理由是「太重」**（2026-07-27 与 yuandesheng 确认）：
> 均价 951₽ / 重量 4.7kg / 体积 11.04L，**价值密度只有 0.202 ₽/g**。这类低价重货头程运费就吃光利润，
> **本来就只在俄罗斯本地卖，不做跨境** —— 哪怕它退货率只有 5.15%、销售额 836 万₽ 看着漂亮。
>
> ⚠️ 但这条判断**没有被一致执行**。保留的 587 行里，价值密度比猫砂更低的还有 11 条：
> 蒸馏水 5L `0.072 ₽/g`（7.4kg）、25kg 工业盐 `0.112`、桦木柴 `0.126`（11.6kg）、5L 洗衣液 `0.127`（6.4kg）、
> 陶粒 `0.155`、洗衣粉 `0.160`… 保留组价值密度中位数是 `1.642 ₽/g`，这些都低了一个数量级。
> **所以这不是一条能复现的筛选规则，是删了一行没删干净。要落 SOP 必须写成硬门槛（见 §6.3 ④）。**

### 6.2 顺带做的格式优化（这部分是好事）

**11 列从文本变成了真数值**：月搜热度、月搜增长、商品数、竞对数、竞品数、评论数、评分、市场空间、商品可见度、转化集中度、退货取消率。
其中 3 个百分比列套了百分比格式（`0.00%` 为主，混着 `0%` 和空值的 `General`，说明是手工刷的、漏了几格）。

**仍然是文本的**：排名、关键词、类目、图片 URL、销售方式、`1120₽` 平均价格、销量、`40446₽` 销售额、`406 g` 重量、`3.26 L` 体积。

意义：数值列现在能直接排序/筛选/透视，不用再 `substitute` 掉 `%`。这是这份文件相对「原」唯一无争议的改进。

### 6.3 🔴 四个必须知道的坑

**① 两个「市场空间」同名。** 新插的第 9 列和 Seerfar 原生的第 17 列表头**一字不差**。
两者口径根本不同：

| | 列 | 口径 | 缺失 |
|---|---|---|---|
| 新加的 | 第 9 列 | 月搜热度 ÷ **商品数**（全站在售数） | 252/589 = **42.8%** 算不出来 |
| Seerfar 原生 | 第 17 列 | ≈ `round(月搜热度 ÷ **竞品数**)`（实测 1456/1458 命中） | 0 |

任何按列名取数的程序（pandas / openpyxl 按 header 建索引）会静默取到其中一个，**行为不确定**。

**② 第 9 列存的是活公式不是值**，且 252 行缓存值是字符串 `#DIV/0!`（因为「商品数」在原始导出里有 44.8% 为空）。
下游 `float()` 直接抛异常，落库会污染字段。

**③ 「排名」前 653 名是伪排序。** 因为 `#DIV/0!` 被 Excel 降序顶到最前面，改文件的**前 252 行（排名 1..653）全是算不出比值的行**，
真正有比值的 337 行排在 655..1459。**改文件的「排名」也不能和「原」对照**——同一个词 `дамплинг` 在原是 6、在改是 3。

**④ 低退货率 ≠ 跨境能做——缺的是重量/体积门槛。** 退货率这一刀完全不管物流，两头都漏：

| 漏的方向 | 留下来的例子 | 为什么不能做 |
|---|---|---|
| **贵重大件**（18 条 >20000₽） | 椭圆机 `62.9kg / 409.9L`、除雪机 `54.5kg`、酒柜 `51018₽` | 小包根本发不了；退货率低只是因为没人随手退大家电 |
| **低价重货**（11 条比手删的猫砂还低，9 条 < 0.2 ₽/g） | 蒸馏水 5L `0.072 ₽/g`、25kg 工业盐 `0.112`、桦木柴 `0.126`、5L 洗衣液 `0.127` | 头程运费直接吃光利润，**只在俄罗斯本地卖**。§6.1 手删的猫砂就是这一类，但同类没删干净 |

保留组重量 max 仍达 `67.2kg`、体积 max `524L`。**建议落成硬门槛**：重量 ≤ 2000g 且 体积 ≤ 10L 且 价值密度 ≥ 0.5 ₽/g，
比「人工看一眼删一行」可复现得多。

### 6.4 这一刀在选品上换掉了什么

| 指标（中位数） | 原 1460 | 改 589 | 被删的 871 |
|---|---|---|---|
| 平均价格 | 1612₽ | **781₽** | 3774₽ |
| 销量 | 324 | **910** | 131 |
| 评论数 | 3410 | **9958** | 1777 |
| 月搜热度 | 8018 | 7906 | 8131 |

**流量几乎没损失，品类整个换掉了**：从「高价低频、强 SKU 差异」换成「低客单价日用消耗品」。
智能手机 140→4、智能手机壳 20→0、耳机 11→0、电动扭扭车 11→0；而牙膏 16/16、速溶咖啡 10/10、调料 8/8、肥料 8/8 **全部留存**。
类目数从 593 收到 270。含拉丁字母的品牌/机型词占比从 29.4% 降到 16.1%（没清干净，`honor win`、`xiaomi pad 7`、`ayn thor` 仍在）。

> 📌 **可直接抄的结论：`退货取消率` 本来就在导出的 21 列里，是唯一能把 3C 品类整体筛掉的那一刀（智能手机 140→4）。** Seerfar 界面上没有这个筛选项，只能导出后在本地做 —— 已连同重量/体积/价值密度一起写进 **§2.2** 的标准口径。

### 6.5 附：市场空间是什么、为什么要算它

**一句话：市场空间 = 需求 ÷ 供给，衡量「每个竞品 / 商品能分到多少搜索流量」，值越大越像蓝海。**

为什么需要这个数，而不是直接按月搜热度或竞品数排序：

| 单看一个 | 会错在哪 |
|---|---|
| 只看 **月搜热度** | 高热度几乎都是红海——智能手机、品牌机型词搜的人多，竞争也最惨，进去就是炮灰 |
| 只看 **竞品数** | 竞品少但没人搜的词是死词，做了没人买 |
| **两者相除** | 得到「供需失衡度」：搜的人多 × 卖的人少 = 真正的市场缝隙 |

把「热度」和「竞争」两个维度压成一个可排序的值，才能一眼排出「最值得做」的词。这就是 §6.1 步骤 ② 在 `_改.xlsx` 里额外插一列算它的动机。

**两个口径，别混**（承接 §6.3 ①）：

| 口径 | 公式 | 分母含义 | 缺失 |
|---|---|---|---|
| Seerfar 原生（第 17 列） | 月搜热度 ÷ **竞品数** | 直接对手间争夺的烈度 | 0 |
| `_改.xlsx` 自算（第 9 列） | 月搜热度 ÷ **商品数** | 整个品类的拥挤 / 稀缺度 | 42.8% 算不出 |

直觉上分母更大的「÷商品数」更保守（把长尾款也算进供给），**听起来更合理**——这正是它被加进 `_改.xlsx` 的理由。

**但实际排序不可信**（承接 §6.3 ②③）：分母「商品数」在原始导出里有 **44.8% 为空**，导致自算列 42.8% 落成 `#DIV/0!`，降序排序时这些行全被顶到前面 → 前 653 名是伪排序。

**实践结论**：
- 市场空间**只适合当排序参考，不适合当硬筛选门槛**——这也是 **§2.2 的本地四筛没把它列进去**的原因（退货率 / 重量 / 体积 / 价值密度都是硬门槛，市场空间不是）。
- 真要用，优先用 Seerfar 原生那一列（÷竞品数，无缺失）；若坚持 ÷商品数 口径，必须先把「商品数」缺失行处理掉（剔除或估补），否则排序失真。

## 7. 两份文件为什么没走「导出」按钮

> 本节只讲**我们自己导的那两份**。§6 的 `_改.xlsx` 已经被 WPS 重写过（插列、改格式、重排序），**不再与网站导出格式一致**，不能拿它去替换旧文件。

本次实际取数**没有点导出按钮**，而是翻页读取表格数据后在本地生成 xlsx。原因：

| | 导出按钮 | 本次做法 |
|---|---|---|
| 单次行数上限 | **2000** | **5000**（服务端上限，一次到位） |
| 拿 5000 条 | 要拆 3 批再拼，`排名` 列会重复 | 一次完成，`排名` 连续 |
| 落盘位置 | 浏览器下载目录 | 直接写到指定路径 |

产出的 xlsx **与网站导出的格式完全一致**：sheet 名 `Data`、21 个列名逐字同序、单元格格式一致（`3810₽` / `1681 g` / `26.62 L` / `163.97%` / `关键词\n(中文)` / `中文类目\n俄文类目`），可直接替换旧文件。

**唯一差异**：网站导出把 `月搜增长`／`转化集中度`／`退货取消率`／`体积` 四列四舍五入到 1 位小数，本次保留了原始 2 位精度（`163.97%` 而不是 `164.0%`）。信息更全，解析行为不变。

> 📌 如果你只是要一份几百到两千条的表，**直接用导出按钮就行**，本节的做法是为了突破 2000 上限。

## 8. 结果解读的三个坑

**① 榜单里混着品牌机型词。** 前 10 名里 `oneplus 15`、`vivo x300`、`playstation 5` 搜索量大、竞品数看着少——但那是品牌壁垒，不是蓝海。真正能做的是 `электроскутер`（电动滑板车）、`эллиптический тренажер`（椭圆机）这类**通用品类词**。

**② 「查询结果数 = 5000」意味着数据不完整。** 那是服务端封顶，不是真实命中数。看到 5000 就该收紧条件重查。

**③ 「商品数」这一列有近一半是空的。** 蓝海词 1460 行里空 654 行（**44.8%**），未筛选的 5000 行里空 1578 行（31.6%）。
缺失是**系统性**的、不是冷门词才缺（缺失行与有值行的月搜热度、竞品数分布几乎一样；智能手机 90/140 缺、抗压玩具 34/35 缺）。
凡是拿「商品数」当分母算指标，先看这一列 —— §6 那份 `_改.xlsx` 42.8% 的 `#DIV/0!` 就是这么来的。

## 9. 附：列名 ↔ 字段对照

导出文件的 21 列与页面字段的对应关系（用于程序化处理）。**这 21 列的列名逐字同序，三份网站口径文件都一致**；
唯一的例外是 §6 的 `_改.xlsx`——它是 22 列，第 9 列多插了一个也叫「市场空间」的公式列，**按列名取数会取错**。

| xlsx 列 | 页面字段 |
|---|---|
| 排名 | 当次导出内的序号（非全站排名） |
| 关键词 | `query` + `queryCn`，格式 `俄文\n(中文)` |
| 类目 | `categoryInfos[0].titleCn` + `titleRu` |
| 关键词相关产品 | `products[0].imageUrl` |
| 销售方式 | `categoryInfos[0].category.crossBorderSellable` |
| 平均价格 / 销量 / 销售额 | `avgPrice` / `sales` / `revenue` |
| 月搜热度 / 月搜增长 | `searchVolume` / `count30GrowthRate` |
| 商品数 / 竞对数 / 竞品数 | `productCount` / `sellers` / `competingProducts` |
| 评论数 / 评分 | `reviews` / `ratings` |
| 市场空间 / 商品可见度 / 转化集中度 | `marketSpace`（实测 ≈ `round(月搜热度/竞品数)`） / `itemsViews` / `conversionSharing` |
| 重量 / 体积 / 退货取消率 | `weight` / `volume` / `returnCancellationRate` |
