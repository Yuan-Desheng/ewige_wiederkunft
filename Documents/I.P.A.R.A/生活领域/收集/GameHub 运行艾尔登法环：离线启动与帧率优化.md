## GameHub 运行艾尔登法环：离线启动与帧率优化

```meta-bind-embed
[[笔记抬头模块]]
```

> 2026-11-05 实机操作记录：在 Android 盖世游戏中运行 Steam 版《艾尔登法环》，排查 EAC 启动错误并优化游戏内画质。适合日后复查；菜单和兼容性可能随版本变化。

## 一、问题与结果

- 设备：Android 手机，型号 `M098FE`，系统报告 SoC 型号 `SM8850`；通过 USB 调试连接电脑。
- 游戏来源：盖世游戏绑定的 Steam 游戏库，游戏已下载，无需重新下载。
- 初始报错：`Easy Anti-Cheat: Failed to initialize Wine helper buffer`。
- 已验证：通过备份并替换启动入口，游戏两次进入主菜单，游戏显示**脱机模式**；之后成功载入已有存档。
- 限制：此方法绕开反作弊启动器，仅用于离线单人游戏，不能使用官方联机功能。Steam 离线模式已开启。Steam 的离线模式与游戏内的脱机状态是不同设置。

## 二、离线启动修复

### 找到游戏目录

1. 关闭游戏后，进入盖世游戏 → 游戏库 → 《艾尔登法环》旁的菜单 → **PC 引擎设置 → 容器 → 进入虚拟桌面**。
2. 在虚拟桌面文件管理器中进入 `我的电脑 → X: → Game`。这是本次设备的映射路径，其他设备可能不同。
3. 本次目录中存在：

```text
X:\Game\
├── eldenring.exe                 游戏主程序
├── start_protected_game.exe      Steam 默认反作弊启动入口
└── start_protected_game.exe.bak  本次保留的原启动器备份
```

直接双击 `eldenring.exe` 曾未进入游戏，也没有显示明确错误；原因未确定。后来通过盖世游戏正常启动替换后的入口，成功进入游戏。

### 已实施的替换

1. 将原始 `start_protected_game.exe` 复制为 `start_protected_game.exe.bak`，保留原始文件备份。
2. 用 `eldenring.exe` 的副本替换 `start_protected_game.exe`，保留原本的 `eldenring.exe`。
3. 在 **PC 引擎设置 → Steam** 开启“离线模式”，从盖世游戏正常启动并选择 `ELDEN RING`。
4. 若游戏提示无法联机，确认提示后进入脱机模式。观察主菜单右下角的模式标识。

> [!important] 备份与校验
> 本次替换前，原启动器与 `.bak` 的 SHA-256 一致；替换后，启动入口与 `eldenring.exe` 的 SHA-256 一致。保留 `.bak`，不要把游戏主程序当成原反作弊启动器。游戏更新或文件完整性验证可能覆盖替换结果。

### 恢复原启动器

1. 正常退出游戏，重新进入虚拟桌面的 `X:\Game`。
2. 先确认 `start_protected_game.exe.bak` 存在；它是原始启动器的备份。
3. 将当前的 `start_protected_game.exe` 移走或删除，再把 `.bak` 文件恢复为 `start_protected_game.exe`。不要删除 `eldenring.exe`。
4. 按需关闭盖世游戏 Steam 离线模式。恢复启动器不保证该设备上的 EAC 兼容性，原错误可能再次出现。

## 三、帧率优化

本次在圆桌厅堂、角色和视角基本相同的位置，依据盖世游戏性能叠层读取瞬时帧率：

| 阶段 | 游戏内设置 | 观察值 |
| --- | --- | --- |
| 优化前 | 1280×720，画质预设“高”，光线追踪关闭 | 约 16 FPS |
| 第一轮 | 1280×720，画质预设“低”，光线追踪关闭 | 约 20 FPS |
| 第二轮 | 960×540，画质预设“低”，光线追踪关闭 | 约 23 FPS |

以上是单次、短时间的叠层读数，不是基准测试或稳定帧率；战斗、场景、温度和后台负载都会影响表现。960×540 画面较模糊，可按自己的流畅度与清晰度偏好调整。游戏内“自动调整渲染效果”保持开启。

![[Extras/游戏/GameHub艾尔登法环/低画质与540p游戏画面.png]]

*低画质、960×540 设置后的同场景实机画面，叠层显示约 23 FPS。*

### 设置路径

1. 游戏内打开菜单 → **系统 → 画面配置**（显示器图标）。
2. 将“品质配置”从**高**改为**低**，确认光线追踪关闭。
3. 如果游戏提示部分设置尚未套用，通过 **系统 → 结束游戏 → 保存并返回标题画面**，再继续游戏。
4. 若仍然卡顿，将“屏幕分辨率”改为 **960×540**；显示确认倒计时时及时选择“是”，否则会自动恢复原分辨率。
5. 在同一场景观察一段时间并自行感受操作。需要恢复清晰度时，可在同一菜单将分辨率改回 **1280×720**、品质改回“高”。

### 后续排查

- 性能叠层当时显示内存占用约 86%～90%；可尝试关闭不需要的后台应用，再比较相同场景。
- 注意设备散热；长时间高负载及充电可能增加热量。
- 盖世游戏 **性能 → AI 超级插帧**本次保持停用。插帧可能改变观感，也可能增加延迟或伪影；原生帧率依然要单独观察。
- 尚未对盖世游戏图形驱动、VKD3D 版本或模拟器分辨率做对照测试，不应将效果归因于这些未验证设置。

## 四、检查清单

- [ ] 游戏可以从盖世游戏正常启动，主菜单显示脱机模式。
- [ ] 原启动器 `.bak` 仍存在；确认备份后再做恢复或更新操作。
- [ ] 画质为低、分辨率为 960×540；如需恢复，改回高和 1280×720。
- [ ] 在实际游玩场景观察帧率和操作延迟，不以标题画面 FPS 作为结论。
- [ ] 不清除盖世游戏数据或卸载游戏来处理这些设置，以免影响本地数据。
