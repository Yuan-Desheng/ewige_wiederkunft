### 5. 代码质量问题

#### 5.1 相对时间解析缺少小时级别 — `youtube_channel_videos_spider.py:44-105`

- 遗漏了 "X小时前" / "X hours ago" 的处理
- 遗漏了 "刚刚" / "just now" 的处理
- **影响**: 最近几小时内的视频无法精确过滤

#### 5.2 日期过滤基于近似时间 — 边界数据丢失

- `_is_video_in_range` 和 `_should_stop_paging` 都基于相对时间
- "2天前" 可能是 1.5天前也可能是 2.5天前
- **建议**: 增加 `get_video_info` 调用获取精确日期

#### 5.3 游标记录无限积累 — `pipelines.py:724-728`

- 每次爬取都 INSERT 新游标，从不清理旧记录
- **建议**: resume 成功后删除该 channel_id 的旧游标

#### 5.4 view_count 字符串需多处重复解析

- `items.py:1702` 定义为 `String(128)`
- `convert_posts.py:413` 有 `_parse_youtube_view_count()` 再次解析
- **建议**: pipeline 层直接转换为数字存入

#### 5.5 _parse_count 不支持英文大数单位 — `youtube_profile_spider.py:230-249`

- 只处理了 "万" 和 "亿"，没有处理 "K" / "M" / "B"
- 如果 API 返回 "2.5M subscribers" 会解析为 2
- **影响**: 英文格式下粉丝数严重错误

```python
def _parse_count(self, text):
    if not text:
        return 0
    import re
    match = re.search(r'([\d,]+(?:\.\d+)?)', str(text))
    if not match:
        return 0
    num_str = match.group(1).replace(',', '')
    try:
        num = float(num_str)
    except ValueError:
        return 0
    text_str = str(text)
    if '万' in text_str:
        num *= 10000
    elif '亿' in text_str:
        num *= 100000000
    elif 'K' in text_str.upper():
        num *= 1000
    elif 'M' in text_str.upper():
        num *= 1000000
    elif 'B' in text_str.upper():
        num *= 1000000000
    return int(num)
```

## 四、数据缺口专项分析：接入 get_video_info_v2

### 4.1 当前 yuqing_post_info 中 YouTube 数据为空的字段

在 `scripts/convert_posts.py:401-443` 中，YouTube 视频转换时以下字段**硬编码为 0 或空**：

```python

post_comment_count=0,           # 无法获取
post_like_and_collect_count=0,  # 无法获取

post_type=_determine_post_type("YouTube"),  # 硬编码 ["视频"]
```

### 4.2 get_video_info_v2 能解决什么

**接口端点:** `GET /api/v1/youtube/web_v2/get_video_info_v2`
**参数:** `video_id` (必选), `need_format=true` (默认)
**费用:** $0.001/次

**need_format=True 时返回字段：**

| 返回字段 | 说明 | 解决的数据缺口 |
|----------|------|---------------|
| `publish_date` | **精确发布日期** (如 "2026-04-04") | 解决 `post_time` 不准确的问题（当前基于"2天前"近似推算） |
| `view_count` | **精确观看数** (数字，如 4417277) | 解决 `post_view_count` 文本解析不精确的问题 |
| `keywords` | **视频标签数组** (如 ["comedy", "podhub"]) | 解决 `post_keywords` 为空的问题（当前仅从 description 提取 #hashtag，大部分视频没有） |
| `length_seconds` | **精确时长**（秒） | 补充 `duration_seconds` 字段 |
| `chapters` | **视频章节列表** | 可用于内容分段分析 |
| `captions` | **字幕信息** | 可用于内容分析 |
| `description` | 完整描述 | 可补充当前可能截断的描述 |
| `author` | 作者名称 | 可校验数据一致性 |
| `rating` | 评分 | 新增字段 |

### 4.3 get_video_info_v2 不能解决的

| 缺口 | 说明 | 解决方案 |
|------|------|---------|
| `post_comment_count` | V2 不返回评论数 | 需调用 `get_video_comments` 端点获取评论列表后计数 |
| `post_like_and_collect_count` | V2 不返回点赞数 | V1 `get_video_info` 有 `like_count_text` 字段（但提取不稳定），或尝试 V1 接口 |
| `post_forward_count` | YouTube 无转发概念 | 永远为 0，无法解决 |

### 4.4 V1 vs V2 对比

| 特性 | get_video_info (V1) | get_video_info_v2 (本方案) |
|------|--------------------|---------------------------|
| 核心字段稳定性 | 部分场景提取不稳定 | **更稳定** |
| 精确发布日期 | 有 | 有 |
| 精确观看数 | 有 | 有 |
| keywords | 有 | 有 |
| `like_count_text` | **有** | **无** |
| `is_verified` | 有 | 无 |
| `subscriber_count_text` | 有 | 无 |
| `merchandise`/`endscreen` | 有 | 无 |
| 特殊视频(年龄限制等) | 可能失败 | **更可靠** |

**建议策略:** 优先使用 V2 获取稳定核心字段，对需要点赞数的视频**额外调用 V1** 获取 `like_count_text`。

#### 步骤2：新建 youtube_video_detail spider

**文件:** 新建 `tikhub_scraper/spiders/youtube_video_detail_spider.py`

**逻辑:**
1. 从 `tkh_youtube_channel_videos` 查询 `detail_fetched=False` 或 `publish_date IS NULL` 的视频
2. 批量调用 `get_video_info_v2` 获取精确数据
3. 可选：调用 `get_video_info` (V1) 获取 `like_count_text`
4. 更新 `tkh_youtube_channel_videos` 表中的对应记录

```python
# 伪代码逻辑
class YouTubeVideoDetailSpider(scrapy.Spider):
    name = 'youtube_video_detail'

    def start_requests(self):
        videos = self._load_unfetched_videos()
        for video in videos:
            url = f"https://api.tikhub.io/api/v1/youtube/web_v2/get_video_info_v2?video_id={video['video_id']}&need_format=true"
            yield scrapy.Request(url, callback=self.parse, meta={'video': video})

    def parse(self, response):
        data = json.loads(response.text)
        if data.get('code') != 200:
            return
        api_data = data['data']

        item = YouTubeChannelVideoItem()
        item['video_id'] = api_data.get('video_id')
        item['publish_date'] = api_data.get('publish_date')  # 精确日期
        item['view_count_exact'] = api_data.get('view_count')  # 精确数字
        item['keywords'] = api_data.get('keywords', [])  # 关键词列表
        item['length_seconds'] = api_data.get('length_seconds')
        item['chapters'] = api_data.get('chapters')
        item['rating'] = api_data.get('rating')
        item['detail_fetched'] = True
        yield item

    def _load_unfetched_videos(self):
        """从数据库加载未获取详情的视频"""
        session = get_session()
        videos = session.query(YouTubeChannelVideo.video_id).filter(
            (YouTubeChannelVideo.detail_fetched == False) |
            (YouTubeChannelVideo.detail_fetched == None) |
            (YouTubeChannelVideo.publish_date == None)
        ).limit(500).all()
        session.close()
        return [{'video_id': v.video_id} for v in videos]
```
