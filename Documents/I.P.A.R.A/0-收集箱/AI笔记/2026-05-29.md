### P0 — 必须修改（数据准确性）

**1. `view_count` 从 String 改为 BigInteger，在 pipeline 中解析**

改动文件: `items.py`, `pipelines.py`, `youtube_channel_videos_spider.py`

```python
# items.py - YouTubeChannelVideo 表
view_count = Column(BigInteger, default=0, comment='观看次数(数值)')  # 改为数值
view_count_text = Column(String(128), comment='观看次数(原始文本)')  # 保留原始文本

# pipelines.py - YouTubeVideoPipeline.process_item 中
# 对 YouTubeChannelVideoItem，解析 view_count 字符串为数字
import re
def _parse_view_count(text):
    if not text:
        return 0
    text = str(text)
    match = re.search(r'([\d,.]+)', text)
    if not match:
        return 0
    num_str = match.group(1).replace(',', '').replace('.', '')
    try:
        num = int(num_str)
    except ValueError:
        return 0
    if '万' in text:
        num *= 10000
    elif '亿' in text:
        num *= 100000000
    elif 'K' in text.upper() or 'k' in text:
        # 需要更精确处理小数点
        pass
    return num
```
