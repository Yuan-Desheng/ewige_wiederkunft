### 问题与解决

1. **TikHub API 认证问题 (403错误)**：初次执行时 API token 过期，重置后恢复正常
2. **X 平台账户暂停**：用户 peach_pachara 账户被暂停，无法获取有效数据
3. **YouTube 部分 400 错误**：6 个用户可能不存在或账号已关闭

### 基础知识点

1. **Scrapy 爬虫框架**：
   - 使用 `scrapy crawl <spider_name>` 命令执行爬虫
   - 爬虫位于 `tikhub_scraper/spiders/` 目录
   - 各平台爬虫：tiktok_profile, instagram_profile, x_profile, youtube_profile

2. **TikHub API**：
   - 需要 Bearer Token 认证
   - API endpoint: `https://api.tikhub.io/api/v1/`
   - Token 配置在 `.env` 文件中的 `TIKHUB_API_TOKEN`

3. **数据库操作**：
   - 使用 SQLAlchemy ORM
   - 模型定义在 `items.py`
   - Pipeline 处理数据持久化

4. **MinIO 图片上传**：
   - 通过 SSH 隧道连接 MinIO 服务器
   - 自动上传用户头像和背景图
   - 图片 URL 存储在数据库表中
