### 会话①｜挂载 NAS 为网络磁盘位置（局域网 + Tailscale 双路径）

- **领域 / 标识**：学习领域 · Linux · NAS SMB 网络磁盘 · DXP4800（极空间）
- **日期范围**：2026-07-23（UTC+8）
- **做了什么**：把内网 NAS（DXP4800，IP `192.168.66.170`，已自带 Tailscale `100.92.228.2`）挂为 Ubuntu 24.04 笔记本的网络磁盘位置，并实现"局域网优先、挂了走 Tailscale、局域网恢复自动切回"。

#### 关键结论与决策

1. **NAS 网络侦察（必做第一步）**：`ping` + `nc -zv` 探三个端口：445（SMB）、2049（NFS）、9999（web 管理）。本机 NAS 只开了 9999，SMB/NFS 都关 → 必须先去 NAS web 后台（`http://dxp4800-fddb.local:9999`，管理员 `nas-admin` / 密码 `【已脱敏】`）启用 SMB。
2. **共享名枚举**：`apt install smbclient cifs-utils` 后跑 `smbclient -L //192.168.66.170 -U user%pass -m SMB3`，拿到共享列表。本 NAS 共享：`personal_folder`（admin 家目录，通用）、`docker`、`供应链文档`、`项目汇总`。选 `personal_folder` 挂载最稳。
3. **凭据分离**（关键安全点）：密码绝不写进 fstab。新建 `/etc/samba/nas-dxp4800.cred`，`chmod 600`，内容只有 `username=...` + `password=...` 两行。fstab 用 `credentials=...` 引用。
4. **fstab 自动挂载（`_netdev,x-systemd.automount`）**：NAS 不在线时不阻塞开机，第一次访问目录时按需挂载。`uid=1000,gid=1000` 让挂载点归当前用户所有。
5. **Tailscale 复用（不需要新装）**：`tailscale status` 发现 `dxp4800-nas 100.92.228.2` **已经在线**（前主人装的，账户 `zhanwei.cui@`），`tailscale ping` 走 `via 192.168.66.170:41641` 1ms 直连 → 这台 NAS 已经接在你的 Tailscale 网里，**直接用 `100.92.228.2` 当远程入口**。
6. **智能切换脚本 `~/bin/nas-switch`**：fstab 不能同 target 写两条 cifs entry（mount 命令永远选第一条，切换失败），解法是脚本完全脱离 fstab，靠 `mount -t cifs ... -o credentials=...,sec=ntlmssp` 手动挂。每次切：测 LAN 445 → 通则切局域网，否则切 Tailscale，失败则回退。
7. **sudoers 免密 mount**：脚本以 yuan 身份跑 `sudo -n mount`，需要 `/etc/sudoers.d/nas-mount` 允许 yuan 无密码跑 `/usr/bin/mount` `/usr/bin/umount` `/usr/sbin/mount.cifs`（限定三条命令，权限最小化）。
8. **systemd 自动切**：`/etc/systemd/system/nas-switch.service` `Type=oneshot` + `WantedBy=multi-user.target`，开机跑一次 `nas-switch prefer`。
9. **重要坑**：`umount` 失败时 cifs 默认会 busy，**不能 cd 到挂载点再 umount**（当前目录把 handle 锁死）；先 `cd /home/yuan` 或别处再卸。`umount -l` 强制 lazy 卸可救急但有 stale 风险。
10. **现场遗留问题**：本次会话结束前发现 NAS LAN 端 `192.168.66.170:445` ping 不通了（Tailscale 100.92.228.2 仍通），自动切到 Tailscale 挂载点。NAS 物理层 / 网段问题未排查，TODO 待查路由器。

#### 一句话踩坑

fstab 同 target 不能写两条 cifs entry（mount 永远选第一条，切换路径失效），解法是脚本脱离 fstab、完全用 `mount -t cifs` 命令挂载；同时 umount 必须在 cd 出挂载点后执行，否则 `device is busy`。
