# 协同仿真模块 /simulator 页面重构 — 完整修改提示词

**面向角色**：frontend-dev 开发者
**模块归属**：模块五 — 虚拟电厂协同仿真 → 5.1 边缘仿真沙盘
**修改类型**：页面重构 + 功能增强
**优先级**：P0（阻塞业务核心场景）

---

## 一、当前问题汇总

| # | 问题 | 根因 |
|---|------|------|
| 1 | 当前仅支持填写单一缺口量，无法覆盖多时间段缺口的复杂场景 | 缺口输入只提供单一数字字段 |
| 2 | 场景设置与缺口设置混在同一区块，职责不清 | 缺少区块化布局，两个不同语义的内容挤在一起 |
| 3 | 时间选择（日期/时段）与天气预报未联动 | 时间变了，天气预报数据未同步刷新 |
| 4 | 缺少第四季度预测值填写入口 | 只有"缺口量"一种输入模式，电力业务通常以第四季度为基准 |
| 5 | 导出功能缺失 | 仿真结果只能看，无法导出用于汇报 |

---

## 二、整体页面布局重构

### 2.1 布局原则

页面采用 **左右两栏 + 底部结果区** 的三段式布局：

```
┌─────────────────────────────────────────────────────┐
│  Header：协同仿真 · 边缘仿真沙盘                         │
├───────────────────┬─────────────────────────────────┤
│                   │                                 │
│  区块A             │  区块B                          │
│  场景配置          │  数据缺口设置                    │
│  (Scenario Config) │  (Data Gap Settings)           │
│                   │                                 │
│  - 预设场景下拉    │  - 输入模式切换（缺口量/Q4预测值） │
│  - 自定义场景      │  - 多时间段输入表格              │
│  - 天气预报联动     │  - 每30分钟一个时间格             │
│                   │                                 │
├───────────────────┴─────────────────────────────────┤
│  区块C：仿真结果展示 + 一键导出                          │
│  - 差额 / 百分比 / 趋势图 + 导出按钮                     │
└─────────────────────────────────────────────────────┘
```

### 2.2 视觉规范

- **区块A（左栏）**：固定宽度 360px，右侧可自适应
- **区块B（右栏）**：flex: 1，最小宽度 600px
- **区块间分割**：使用 1px #E5E7EB 分隔线，带 24px 内边距
- **区块标题**：字号 16px，字重 600，颜色 #1F2937，底部 1px 分隔线
- **区块内容**：字号 14px，颜色 #374151，行高 1.6
- **字体**：使用系统默认字体栈（-apple-system / PingFang SC / Microsoft YaHei）
- **颜色系统**：主色 #2563EB，警告色 #F59E0B，危险色 #EF4444，成功色 #10B981，背景色 #F9FAFB，白色卡片 #FFFFFF

## 三、区块A — 场景配置（Scenario Configuration）

### 3.1 任务描述

将场景配置从原有混杂区域拆分为独立区块，提供清晰的场景管理能力。

### 3.2 包含要素

#### 3.2.1 预设场景下拉（Select）

**功能**：快速选择已有预设场景，自动填充相关参数。

**下拉选项（须与后端对齐，下拉内容由 API 返回）**：

| 场景ID | 场景名称 | 说明 |
|--------|----------|------|
| scenario_high_temp | 高温红色预警 | 当日最高气温 ≥ 40°C，空调负荷激增 |
| scenario_cold_wave | 寒潮橙色预警 | 48h内降温幅度 ≥ 12°C，取暖负荷骤升 |
| scenario_peak_demand | 夏季尖峰负荷 | 工作日下午14:00-18:00用电高峰 |
| scenario_q4_winter | 第四季度冬季 | 11月-12月，供暖 + 工业年末冲刺叠加 |
| scenario_custom | 自定义场景 | 用户手动配置参数 |

**UI 要求**：
- 使用 `<select>` 原生控件或等效下拉组件（推荐 Select2 / Ant Design Select）
- 默认选中 `scenario_custom`，新用户首次进入为空白状态
- 下拉选项显示：场景名称 + 简短说明（tooltip 展示完整说明）
- 选中预设场景后：自动将对应参数（日期范围、气象条件、缺电量级）填入区块B，**覆盖**用户之前的手动输入（须弹窗确认："切换场景将覆盖当前输入，是否继续？"）

#### 3.2.2 自定义场景编辑区

**功能**：当选择 `scenario_custom` 时，或在预设场景基础上微调时，显示可编辑字段。

**编辑字段**：

| 字段名 | 类型 | 说明 | 必填 |
|--------|------|------|------|
| 场景名称 | TextInput（≤20字符） | 用户自定义名称 | 是 |
| 日期范围 | DateRangePicker | 仿真日期起止，支持多日连续仿真 | 是 |
| 时段选择 | TimeRangePicker | 开始时间 - 结束时间，支持跨天 | 是 |
| 气象条件 | Select（温度/湿度/风速） | 对接气象数据接口，见 3.3 | 是 |
| 备注 | TextArea（≤200字符） | 可选，说明本次仿真背景 | 否 |

#### 3.2.3 天气预报联动

**功能**：选择日期后，自动调取对应日期的天气预报数据，展示在场景配置区块内，并**同步影响区块B的缺口计算逻辑**。

**技术要求**：
- 调用后端天气 API（接口地址：`/api/weather/forecast?city=浙江省&date=2026-01-15`），返回温度、湿度、风速、天气状况
- **联动逻辑**：当 DateRangePicker 选择的日期发生变化时，自动重新请求天气预报数据，无需用户手动刷新
- 若 API 请求失败，Weather Card 显示"天气数据获取失败，请手动输入气象条件"，并允许用户手动填写气温（输入框 fallback）
- 天气数据作为**隐式参数**传入区块B的缺口计算模型（后端根据温度修正负荷预测曲线）

## 四、区块B — 数据缺口设置（Data Gap Settings）

### 4.1 任务描述

支持多时间段缺口的复杂输入场景，提供两种输入模式，并允许每30分钟填写一个独立的缺口量或预测值。

### 4.2 输入模式切换

**功能**：在区块B顶部提供 Tab 切换，控制整个区块的输入语义。

```
[ ○ 模式一：填写缺口量 ]    [ ○ 模式二：填写第四季度预测值 ]
```

- Tab 切换时，清空当前输入（须弹窗确认）
- 当前激活 Tab 显示实色（主色 #2563EB 背景，白色文字）
- 未激活 Tab 显示边框样式（#E5E7EB 边框，#6B7280 文字）

---

## 五、模式一 — 填写缺口量

### 5.1 任务描述

用户直接填写各时间段的电力缺口量（单位：MW），支持每30分钟一个时间段，共48个时间段（00:00 - 23:30）。

### 5.2 时间段表格设计

**详细规范**：

1. **时段分组**：将全天48个时段按用电特征分为5组，每组以图标 + 文字标签标识：
   - 🌙 凌晨：00:00 - 06:00（12个时段）
   - 🌅 早晨：06:00 - 09:00（6个时段）
   - ☀️ 上午/🌤️ 下午：09:00 - 17:00（16个时段）
   - 🌆 傍晚：17:00 - 20:00（6个时段）
   - 🌙 晚间：20:00 - 24:00（8个时段）

2. **输入控件**：使用 NumberInput，支持键盘上下键 ±0.5 调节，允许小数（精度0.5MW），最小值 0，最大值根据后端可调能力上限

3. **尖峰标注**：当某时段缺口量 > 该地区历史峰值的 80%，自动在右侧标注 🔥 尖峰

4. **快捷操作**：
   - **一键均分**：点击后弹出均分设置弹窗（输入总量 MW → 自动均分到各时段，支持上下调），确认后填入
   - **导入 CSV**：支持上传 CSV 文件（格式：`time_slot,gap_mw`），批量填充；须前端校验格式

5. **复制/粘贴**：支持整行复制、整组复制、整日复制（右键菜单或工具栏按钮）

6. **数据联动**：当用户在模式一下修改任何时段值时，区块C的实时预览图须同步更新（防抖 300ms）

---

## 六、模式二 — 填写第四季度预测值

### 6.1 任务描述

用户不直接填写缺口量，而是填写第四季度（Q4）的预测负荷值，系统**自动计算**缺口量：`缺口量 = Q4预测值 - 实时基准值`（基准值由后端根据历史数据计算返回）。

**规范**：
- 基准值列**仅展示，不可编辑**（灰色背景 #F3F4F6）
- 预测值列可编辑，输入后**实时**计算缺口量并显示在第三列
- 缺口量为**正数**显示 🔺（红色↑，表示供电不足），**负数**显示 🔻（绿色↓，表示供电盈余）
- 支持与模式一相同的快捷操作（均分、CSV导入）
- 底部汇总同模式一

## 七、仿真结果展示（区块C）

### 7.1 任务描述

在页面底部实时展示仿真计算结果，包含数值、百分比和趋势图。

### 7.2 结果指标卡

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  全天缺口总量  │  峰值时段缺口  │  平均缺口率    │  可调资源覆盖  │
│    3,250 MW  │    760 MW     │     15.3%     │     82.5%     │
│    ↑12.5%    │  (17:00-20:00)│  ↑较昨日+2.1%  │  ↓较昨日-1.3% │
└──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘
```

**指标说明**：
- 全天缺口总量：所有48个时段缺口量之和（单位：MW·h 或折算为万吨标准煤）
- 峰值时段缺口：当日 17:00-20:00 时段缺口的累加值
- 平均缺口率：缺口量 / 预测需求总量 × 100%，以百分比表示
- 可调资源覆盖：可调资源总量 / 缺口总量 × 100%

### 7.3 趋势图（折线图）

**使用 ECharts 或等效图表库**，展示以下曲线：

1. **缺口量时序曲线**（主图）：
   - X轴：时间（00:00 - 23:30，每30分钟一个刻度）
   - Y轴左：缺口量（MW）
   - Y轴右：温度（°C），叠加温度辅助线（虚线）
   - 数据系列：缺口量（实线 + 区域填充）、基准值（虚线）
   - 交互：hover 显示 tooltip（时间、缺口量，温度）

2. **差额和百分比表格**（副表，紧邻图表下方）

### 7.4 结果计算触发逻辑

- 用户每次修改区块A或区块B的数据后，**自动触发重新计算**（防抖 debounce 800ms），无需手动点击"计算"按钮
- 计算中显示 Loading 状态（骨架屏或 spinner），计算完成后自动渲染结果
- 若某时段数据为空，图表中对应点显示为断点，不做连线

## 八、一键导出 Excel

### 8.1 任务描述

提供一键导出功能，将仿真结果按三个维度（全省用户 / 行业 / 地市）分别导出为 Excel 文件。

### 8.2 导出按钮位置

位于区块C顶部右侧，`[导出 Excel ▾]` 按钮，点击展开子菜单。

### 8.3 导出维度子菜单

```
导出 Excel
├── 📊 按全省用户维度导出
├── 🏭 按行业维度导出
└── 📍 按地市维度导出
```

### 8.4 各维度导出格式

#### 8.4.1 全省用户维度

```excel
【Sheet 1: 缺口汇总】
| 日期 | 时段 | 全省预测需求(MW) | 实际可供(MW) | 缺口量(MW) | 缺口占比(%) |

【Sheet 2: 全省用户明细】
| 用户ID | 用户名称 | 用户类型 | 时段 | 缺口分摊量(MW) | 响应潜力(MW) |
```

#### 8.4.2 行业维度

```excel
【Sheet 1: 行业汇总】
| 日期 | 行业 | 预测需求(MW) | 可供量(MW) | 缺口量(MW) | 缺口占比(%) | 参与用户数 |

【Sheet 2: 行业明细 - 工业】
| 日期 | 时段 | 子行业 | 预测(MW) | 缺口(MW) | 可调资源(MW) | 覆盖率 |
```

#### 8.4.3 地市维度

```excel
【Sheet 1: 地市汇总】
| 日期 | 地市 | 预测需求(MW) | 可供量(MW) | 缺口量(MW) | 缺口占比(%) | 参与用户数 |

【Sheet 2: 地市明细 - 杭州】
| 日期 | 时段 | 行业 | 预测(MW) | 缺口(MW) | 可调资源(MW) | 覆盖率 |
```

### 8.5 导出技术要求

- **导出库**：使用 `xlsx`（SheetJS）或等效库
- **文件名格式**：`协同仿真结果_{维度}_{日期}_{时间戳}.xlsx`，例如：`协同仿真结果_地市_20260115_170320.xlsx`
- **单次导出**：每个维度生成独立 Excel 文件
- **大文件处理**：若数据量超过 5000 行，显示进度条（ProgressBar）
- **导出中状态**：按钮显示 Loading 状态，禁用重复点击
- **导出完成**：浏览器自动下载文件，页面顶部 Toast 提示"导出成功，共 X 行数据"
