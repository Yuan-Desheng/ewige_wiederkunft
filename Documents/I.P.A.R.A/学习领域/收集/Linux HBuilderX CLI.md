终端使用方式：

**1. 启动 HBuilderX GUI：**

```bash
cd /opt/HBuilderX && ./cli open
```

**2. 登录（app 打包必须登录）：**

```bash
cd /opt/HBuilderX && ./cli user login --username <用户名> --password <密码>
```

**3. 打开项目：**

```bash
cd /opt/HBuilderX && ./cli project open --path <项目路径>
```

**4. App 打包：**

```bash
cd /opt/HBuilderX && ./cli pack --config <配置文件>
```

**5. 查看 CLI 帮助：**

```bash
cd /opt/HBuilderX && ./cli --help
```
