> [!tip] 一分钟复现
> ① 不可见 Tab 的 composable 加可选 `enabled?: Ref<boolean>`，`!enabled || enabled.value` 才请求；② 页面 `reactive(visited)` + `watch(activeSubTab)` 置真、`enabled = computed(() => visited.x)`；③ 骨架条件统一 `loading && apiData === null`（命名 `xxxLoadingFirst`）；④ 图表/卡片 `el-skeleton`，表格首屏骨架 + 翻页 `v-loading`；⑤ composable 内 `seq` 自增丢弃过期响应。

## 一、原理

**问题现象**：页面打开时白屏 / 先闪一段 mock 假数据再跳成真实值；卡顿感来自首屏一次性并发太多接口。

**瓶颈定位**（本项目实测）：

1. **首屏过度并发**：`index.vue` 在 setup 阶段就实例化 6 个 composable，每个 `watch(..., { immediate: true })` 立即发请求。但页面有 3 个二级 Tab，首屏只显示第一个，**另外 2 个 Tab 的接口首屏不可见却照样请求**。
2. **无占位 → 白屏**：接口未返回时区块是空的。
3. **mock 回退闪假数**：数据走 `apiData ?? mockData` 回退，首屏 `apiData` 为 `null` → 先渲染 mock 假数再跳真值，数字跳动。

**优化思路**（三招，对应三个现象）：

- **分级/懒加载**：不可见 Tab 的接口延迟到「首次进入该 Tab」才请求 → 首屏并发 6 降到 4。
- **骨架屏占位**：接口加载期用 `el-skeleton` 占位，消除白屏。
- **"只在首屏闪一次"的骨架口径**：骨架显示条件不是裸 `loading`，而是 `loading && apiData === null`。这样切筛选签 / 翻页 / 切城市等"已有数据的再请求"不再闪骨架，也顺带遮住 mock 假数。

**约定分工**：图表 / KPI 卡用 `el-skeleton`（块状骨架）；表格首屏用 `el-skeleton`、后续翻页用 `v-loading`（遮罩）。

数据流：

```
setup
  ├─ 可见 Tab 接口        → immediate 请求 → loading=true → 骨架 → 返回后渲染真实/mock
  └─ 不可见 Tab 接口(懒)  → enabled=false 跳过
点击进入某 Tab
  └─ visited[tab]=true → enabled=true → watch 触发 → 首次请求 → 该 Tab 骨架 → 渲染
```

## 二、代码

### 1. 懒加载开关 composable（`enabled?: Ref<boolean>`）

`src/pages/capacity/composables/useAdjustableIndustryDetail.ts`：

```ts
// ==================== 行业能力明细（接口对接） ====================
// 对接 /data/api/adjustable-capacity/industry-detail：city 不传 = 省级全量，
// 传入 = 限定本市。归类口径与 summary 一致，按可调能力降序。
import type { Ref } from 'vue'
import type { ScenarioKey } from '../types'
import { SCENARIO_META } from '../types'
import type { IndustryCapacityRow } from './useCapacityV2'
import { getAdjustableIndustry } from '~/api/capacity'

export function useAdjustableIndustryDetail(
  selected: Ref<ScenarioKey[]>,
  city?: Ref<string | undefined>,
  // 懒加载开关：不传 = 始终请求；传入则仅在 enabled 为 true 后请求
  enabled?: Ref<boolean>,
) {
  const loading = ref(false)
  const apiRows = shallowRef<IndustryCapacityRow[] | null>(null)
  // 快速切换勾选/城市时丢弃过期响应
  let seq = 0

  async function fetch() {
    const current = ++seq
    loading.value = true
    try {
      const res = await getAdjustableIndustry(
        {
          scenarios: selected.value
            .map((k) => SCENARIO_META[k].label)
            .join(','),
          ...(city?.value ? { city: city.value } : {}),
        },
        { silent: true },
      )
      if (current !== seq) return
      const list = res.code === 0 ? res.data?.records : null
      apiRows.value = Array.isArray(list)
        ? list.map((r) => ({
            industry: r.industry,
            users: Number(r.userCount) || 0,
            total: Number(r.capacityKw) || 0,
            per: {
              yf: Number(r.yftgKw) || 0,
              dr: Number(r.xqxyKw) || 0,
              mr: Number(r.jzjxKw) || 0,
            },
          }))
        : null
    } catch {
      // API 失败时保持 null，调用方回落 mock 数据
      if (current === seq) apiRows.value = null
    } finally {
      if (current === seq) loading.value = false
    }
  }

  watch(
    [selected, ...(city ? [city] : []), ...(enabled ? [enabled] : [])],
    () => {
      // 懒加载：未启用时跳过请求，进入对应 Tab（enabled 置真）后再触发
      if (!enabled || enabled.value) fetch()
    },
    { immediate: true, deep: true },
  )

  return { apiRows, loading, refresh: fetch }
}
```

`src/pages/capacity/composables/useAdjustableMonthlyTrend.ts`（不随 `selected` 联动，watch 结构不同，单列 enabled false→true 补请求）：

```ts
// ==================== 月度调节实绩趋势（接口对接） ====================
import type { Ref } from 'vue'
import type { MonthlyCapacityPoint } from '../types'
import { getAdjustableMonthlyTrend } from '~/api/capacity'
import { div } from '~/utils/math'

const KW_TO_WANKW = 10000

export function useAdjustableMonthlyTrend(
  city?: Ref<string | undefined>,
  // 懒加载开关：不传 = 始终请求；传入则仅在 enabled 为 true 后请求
  enabled?: Ref<boolean>,
) {
  const loading = ref(false)
  const apiTrend = shallowRef<MonthlyCapacityPoint[] | null>(null)
  let seq = 0

  async function fetch() {
    const current = ++seq
    loading.value = true
    try {
      const res = await getAdjustableMonthlyTrend(
        { ...(city?.value ? { city: city.value } : {}) },
        { silent: true },
      )
      if (current !== seq) return
      const list = res.code === 0 ? res.data?.months : null
      apiTrend.value = Array.isArray(list)
        ? list.map((m) => ({
            month: m.month,
            yf: div(Number(m.yfKw) || 0, KW_TO_WANKW),
            dr: div(Number(m.drKw) || 0, KW_TO_WANKW),
            mr: div(Number(m.mrKw) || 0, KW_TO_WANKW),
          }))
        : null
    } catch {
      if (current === seq) apiTrend.value = null
    } finally {
      if (current === seq) loading.value = false
    }
  }

  const shouldFetch = () => !enabled || enabled.value

  if (city) {
    watch(
      city,
      () => {
        if (shouldFetch()) fetch()
      },
      { immediate: true },
    )
  } else if (shouldFetch()) {
    fetch()
  }

  // 懒加载：enabled 由 false→true（首次进入历史调节 Tab）时补一次请求
  if (enabled) {
    watch(enabled, (v) => {
      if (v && apiTrend.value === null && !loading.value) fetch()
    })
  }

  return { apiTrend, loading, refresh: fetch }
}
```

### 2. 页面侧：懒加载开关 + "只首屏闪一次"的骨架口径

`src/pages/capacity/index.vue`（setup 部分）：

```ts
// ==================== 子 Tab（行业/历史明细首次进入才请求，降低首屏并发） ====================
const activeSubTab = ref('users')
const subTabs = [
  { key: 'users', label: '用户明细' },
  { key: 'industry', label: '行业明细' },
  { key: 'history', label: '历史调节' },
]
// 记录已访问过的 Tab：未访问的 Tab 不发起接口请求，首屏并发从 6 个降到 4 个
const visited = reactive({ users: true, industry: false, history: false })
watch(activeSubTab, (t) => {
  if (t in visited) visited[t as keyof typeof visited] = true
})
const industryEnabled = computed(() => visited.industry)
const historyEnabled = computed(() => visited.history)

// 各区块首屏骨架口径：仅「尚无任何数据 + 请求进行中」时显示骨架屏
const { apiAggregate, loading: summaryLoading } =
  useAdjustableSummary(selectedScenarios)
const aggregate = computed(
  () =>
    apiAggregate.value ?? aggregateUsers(ALL_USERS, selectedScenarios.value),
)
const aggregateLoading = computed(
  () => summaryLoading.value && apiAggregate.value === null,
)

const { apiItems: rankApiItems, loading: rankLoading } =
  useAdjustableRegionRank(selectedScenarios)
const rankItems = computed(
  () => rankApiItems.value ?? cityRankItems(selectedScenarios.value),
)
const rankLoadingFirst = computed(
  () => rankLoading.value && rankApiItems.value === null,
)

// 行业明细接口（懒加载：进入「行业明细」Tab 后才请求），失败回落 mock
const { apiRows: industryApiRows, loading: industryLoading } =
  useAdjustableIndustryDetail(selectedScenarios, undefined, industryEnabled)
const industryRows = computed(
  () =>
    industryApiRows.value ??
    industryCapacityRows(ALL_USERS, selectedScenarios.value),
)
const industryLoadingFirst = computed(
  () => industryLoading.value && industryApiRows.value === null,
)

// 月度趋势（懒加载：进入「历史调节」Tab 后才请求）
const { apiTrend: monthlyApiTrend, loading: monthlyLoading } =
  useAdjustableMonthlyTrend(undefined, historyEnabled)
const monthlyLoadingFirst = computed(
  () => monthlyLoading.value && monthlyApiTrend.value === null,
)
```

模板把 `xxxLoadingFirst` 透传给各区块的 `loading`（注意 `industry` 用 `v-show` 保 DOM、靠 `visited` 控制请求；`history` 用 `v-if`）：

```vue
<template>
  <div class="capacity-page">
    <CapacityKpiCards
      :aggregate="aggregate"
      :selected="selectedScenarios"
      :loading="aggregateLoading"
    />
    <div class="charts-equal grid grid-cols-1 gap-4 lg:grid-cols-2">
      <RegionRankChart :items="rankItems" zoomable :loading="rankLoadingFirst" />
      <OverlapPieChart :data="overlap" :loading="overlapLoadingFirst" />
    </div>
    <SubTabs v-model="activeSubTab" :tabs="subTabs" />
    <div v-show="activeSubTab === 'industry'" class="sub-content sub-card">
      <IndustryCapacityTable :rows="industryRows" :loading="industryLoadingFirst" />
    </div>
    <div v-if="activeSubTab === 'history'" class="sub-content">
      <HistoryPanel :trend="monthlyApiTrend ?? undefined" :trend-loading="monthlyLoadingFirst" />
    </div>
  </div>
</template>
```

## 四、复现 Checklist

- [ ] **接口懒加载**：不可见 Tab 的 composable 加可选 `enabled?: Ref<boolean>`，`!enabled || enabled.value` 才请求；不传保持原行为（向后兼容）
- [ ] **Tab 访问记录**：页面用 `reactive({ users: true, ... })` 的 `visited` + `watch(activeSubTab)` 置真；`enabled = computed(() => visited.xxx)`
- [ ] **首屏并发核对**：确认首屏只打可见 Tab 的接口
- [ ] **图表/卡片骨架**：复用 `ChartCard` 的 `loading → el-skeleton`；KPI 卡用 `el-skeleton-item` 自定义占位
- [ ] **表格两态**：`v-if="loading && !rows.length"` 显示骨架，`v-else` 的 `el-table` 用 `v-loading` 处理翻页
- [ ] **"只首屏闪一次"口径**：骨架条件统一 `loading && apiData === null`（命名 `xxxLoadingFirst`），不是裸 `loading`
- [ ] **竞态防护**：composable 内 `seq` 自增，过期响应 `if (current !== seq) return` 丢弃
- [ ] **切城市重置**：动态路由页 `watch(routeParam, () => { activeSubTab='users'; visited.xxx=false })`
- [ ] **验证**：`pnpm lint:fix` 0 error + `pnpm build` exit 0；`pnpm dev` 目测首屏骨架→真实数据无 mock 跳变，切筛选签/翻页/切城市不闪骨架

## 五、踩坑记录

- **现象**：切筛选签 / 翻页时图表和卡片反复闪骨架。**原因**：骨架绑定裸 `loading`，再次请求时 `loading` 又变 true。**解决**：骨架条件改 `loading && apiData === null`（只有首屏无数据才闪），表格用 `loading && !rows.length`。
- **现象**：首屏先显示假数据（mock）再跳真值，数字跳动。**原因**：`apiData ?? mockData` 回退 + 首屏 `apiData` 为 `null`。**解决**：首屏直接显示骨架，遮住 mock 渲染。
- **现象**：首屏一次性 6 个接口并发，不可见 Tab 也请求。**原因**：composable `watch(..., { immediate: true })` 挂载即请求。**解决**：加 `enabled` 懒加载开关，Tab 首次进入才请求。
- **现象**：改 composable 签名担心影响其它页面。**原因**：`useAdjustableIndustryDetail`/`useAdjustableMonthlyTrend` 被省级/地市级共用。**解决**：`enabled` 设为**可选**第三参，不传维持原行为。
- **现象**：快速连点筛选签 / 切城市，旧响应覆盖新数据。**原因**：异步请求乱序返回。**解决**：composable 内 `let seq = 0`，每次 `++seq`，返回时 `if (current !== seq) return` 丢弃过期响应。
- **现象**：切到另一个城市，新城市却已把三个 Tab 接口都请求了。**原因**：`visited` 跨城市残留为 true。**解决**：`watch(cityName)` 里重置 `visited.industry/history = false` 并回 users Tab。

## 六、踩坑速查

| 现象 | 根因 | 解决 |
|---|---|---|
| 切签/翻页反复闪骨架 | 骨架绑裸 `loading` | `loading && apiData === null` |
| 首屏先闪 mock 假数 | `api ?? mock` + 首屏 api null | 首屏直接骨架遮住 |
| 首屏并发过多 | `watch immediate` 挂载即请求 | `enabled` 懒加载，Tab 进入才请求 |
| 改签名怕影响其它页 | composable 被多页共用 | `enabled` 设可选，不传维持原行为 |
| 旧响应覆盖新数据 | 异步乱序返回 | `seq` 自增，过期 `return` 丢弃 |
| 切城市三 Tab 都请求了 | `visited` 跨城市残留 | `watch(cityName)` 重置 `visited` |
