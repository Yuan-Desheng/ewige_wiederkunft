## Android Studio 快捷键
1. **快速创建 Widget**：在 dart 文件中输入 `stful` 或 `stless` 出现提示后按回车即可
2. **快速修复**：`Alt + Enter`
3. **自动生成构造函数**：选中 `final` 参数，快捷键：`Alt + Enter`
4. **添加父组件、变为子组件、删除子组件**：`Alt + Enter`
5. **万能的搜索**：双击 `Shift`
6. **查看最近打开的文件**：`Ctrl + E`
7. **重命名**：`Shift + F6`（无需 fn）
8. **查看当前类结构**：`Ctrl + F12`
9. **查看源码**：将光标放到要查看源码的类名或方法名上，长按 `Ctrl` 然后点击
10. **查看类的子类**：选中要查看的类，然后：`Ctrl + B` 或 `Ctrl + Alt + B`
11. **将代码更新到模拟器上**：选中模拟器然后 `Ctrl + R`（注：此功能在 Windows 上可能对应热重载 `Ctrl + \` 或运行 `Shift + F10`，请根据实际需要尝试）
12. **导入类的快捷键**：将光标放在要导入类的上面，然后按 `Alt + Enter`
13. **前进后退**：后退 `Ctrl + Alt + 左箭头`，前进 `Ctrl + Alt + 右箭头`（原 Mac 后退为 `Option+Command+左`，前进应为 `Option+Command+右`，此处已修正）
14. **全局搜索**：`Ctrl + Shift + F`
15. **全局替换**：`Ctrl + Shift + R`
16. **查找引用**：`Alt + Shift + F7`
