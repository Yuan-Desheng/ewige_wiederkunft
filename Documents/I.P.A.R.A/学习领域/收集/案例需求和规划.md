### 创建项目 - 基本目录与 Git 管理

#### 1. 创建适配 web 平台项目

```shell
flutter create --platforms web hm_shop
```

#### 2. 创建基本目录结构

```text
lib/
├── api/          # 存放请求
├── assets/       # 存放资源
├── components/   # 存放公共组件
├── contants/     # 存放常量文件
├── viewmodels/   # 存放类型文件
├── pages/        # 存放页面
├── routes/       # 存放路由配置
├── stores/       # 存放全局状态组件
├── utils/        # 存放工具类
└── main.dart     # 入口
```

#### 3. 创建本地和远程仓库并提交

```bash
git init                               # 初始化仓库
git add .                              # 提交本地仓库到暂存区
git commit -m "初始化仓库"             # 提交本地仓库
git remote add origin <远程仓库地址>   # 添加远程仓库
git push -u origin master              # 推送主分支到远程
```
