### 1. 变量 (`var`)
*   **应用场景**：存储**存储会发生变化**的数据（如：计数器、开关状态、年龄增长）。
*   **关键字**：`var`
*   **核心语法**：`var 变量名 = 值;`
*   **⚠️ 重点注意**：
    *   **类型推断**：一旦第一次赋值，类型即被锁定。
    *   **强类型约束**：不能将已确定类型的变量再次赋值为其他类型（例如 `int` 不能改赋 `String`）。
```dart
void main() {
  var age = 20; // 自动推断为 int 类型
  age = 21;     // ✅ 同类型修改，允许
  // age = "22"; // ❌ 报错：A value of type 'String' can't be assigned to a 'int'
}
```
---
### 2. 编译时常量 (`const`)
*   **应用场景**：存储**绝对不会改变**且**写代码时已知**的数值（如：圆周率 、配置文件的固定 URL）。
*   **关键字**：`const`
*   **核心特点**：
    *   **编译期确定**：程序还没跑起来，值就已经算好了。
    *   **不可改变**：赋值后是深度冻结的。
    *   **性能最优**：多个地方使用相同的 `const` 值，在内存中只占用一份空间（**规范化实例**）。
```dart
void main() {
  const pi = 3.1415926;
  const area = pi * 10 * 10; // ✅ 表达式中也必须全是常量
}
```
---
### 3. 运行时常量 (`final`)
*   **应用场景**：存储**初始化后不再改变**，但其值**必须在程序运行时**才能确定的数据（如：接口返回的数据、当前系统时间、传感器数值）。
*   **关键字**：`final`
*   **核心特点**：
    *   **运行时确定**：在代码执行到这一行时才分配内存并赋值。
    *   **懒加载 (Lazy)**：如果不使用该变量，它可能永远不会被初始化（提高启动速度）。
```dart
void main() {
  // 错误纠正：时间必须用 final，不能用 const
  final currentTime = DateTime.now(); // ✅ 获取当前精确运行时间
  print(currentTime);
  // currentTime = DateTime.now();   // ❌ 报错：final 变量只能赋值一次
}
```
---
### 🚀 核心对比总结（面试必备）

| 维度        | `var` (变量) | `final` (运行时常量)   | `const` (编译时常量)     |
| --------- | ---------- | ----------------- | ------------------- |
| **可否修改**  | **可以修改值**  | **不可修改**          | **不可修改**            |
| **初始化时机** | 随时赋值       | **运行时** (Running) | **编译时** (Compiling) |
| **内存表现**  | 普通内存开辟     | 第一次使用时开辟          | **内存共享**，极省性能       |
| **赋值要求**  | 随便赋值       | 可以通过函数/运算赋值       | **必须是固定值或常量运算**     |
> **💡 黄金法则：**
> 在开发 Dart/Flutter 应用时，请遵循：**优先使用 `const` ⮕ 其次使用 `final` ⮕ 最后才考虑使用 `var**`。这能让你的程序运行更稳健、内存更高效。
