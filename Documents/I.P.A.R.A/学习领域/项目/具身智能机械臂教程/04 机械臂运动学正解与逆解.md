这章把关节角、URDF 和末端坐标接起来。先在纸面验证二连杆，再用同一姿态核对 Python 与课程示教器中的末端位置。视频定位见 [P31–34 运动学与正解](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=31)、[P35–36 逆解](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=35)、[P37–38 末端展示与示教器](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=37)。

### 1. 从关节角计算末端

在平面内设置基座原点，逆时针为正。第一节长 $L_1$、角度为 $q_1$，第二节长 $L_2$、相对第一节转了 $q_2$。因此第二节在基座坐标系中的朝向是 $q_1+q_2$。

$$
x=L_1\cos q_1+L_2\cos(q_1+q_2),\qquad
y=L_1\sin q_1+L_2\sin(q_1+q_2)
$$

![[Extras/机器人/具身智能机械臂视频教程/04-二连杆正逆解.png|900]]

*图 1。左侧用课程 NumPy 示例的连杆长度和角度计算末端。右侧用等长连杆展示同一目标的两个解。*

使用列向量时，可把旋转和位移放进一个齐次矩阵。在二维示例中，每节的变换为 $T=R(q)\operatorname{Trans}(L,0)$，叠加为 $T_{02}=T_{01}T_{12}$。末端位置就在 $T_{02}$ 最后一列的前两项。三维换成 $4\times4$ 矩阵，读前三项。变换顺序、坐标系和使用的向量约定应在整个计算链里一致。

### 2. 跑课程原例并核对输出

在 `代码/机械臂运动学.zip` 解压后的目录运行下面的命令。三个脚本均可从原始资料定位，运行这些数学示例无需连接串口。

```bash
python -m pip install numpy matplotlib
python 07_numpy_ikpy_fk.py
python forward_kinematics/forword_kinematics_01.py
```

1. NumPy 示例使用 `L1=1.0`、`L2=0.8`、`q1=30°`、`q2=45°`。实跑矩阵连乘得到 `(1.0731, 1.2727)`。原脚本最后一行把理论值写成了 `(1.0733, 1.2821)`，可代回上面的公式复核。
2. 三维示例提示输入时键入 `0 0 0 0 0 0`。课程模型的夹爪位置应为约 `(-0.0129, -0.0132, 0.4280) m`。样例第三组的 90° 会略超 URDF 中的 `1.570 rad` 边界，原因是 $\pi/2\approx1.570796$。
3. 再打开 `课程ppt/二连杆运动学模拟器.html` 或 `3D机械臂正解计算模拟器.html`，比较零位、单轴转动、两轴联动。若滑块范围或连杆长度与 Python 例子不同，先把参数统一。

### 3. 从末端目标反推关节角

对于不限位的理想平面二连杆，先检查目标距离 $r=\sqrt{x^2+y^2}$ 是否在 $[|L_1-L_2|,L_1+L_2]$ 内。由余弦定理算出 $c_2=(x^2+y^2-L_1^2-L_2^2)/(2L_1L_2)$，再取 $q_2=\pm\arccos(c_2)$。随后用 $q_1=\operatorname{atan2}(y,x)-\operatorname{atan2}(L_2\sin q_2,L_1+L_2\cos q_2)$ 求第一关节角。

- **解析法练习。** 运行 `08_ik_demo_几何解析法.py`。把 $L_1=L_2=1$，目标设为 `(1, 1)`，应有 `(0°, 90°)` 和 `(90°, -90°)` 两解。试 `(2.1, 0)` 会不可达。试 `(2, 0)` 会到伸直边界，两支合并。原例在等长且目标为原点时会除零，复现时先避开原点，扩展计算时单独处理重合状态。
- **数值法练习。** 运行 `09_ik_demo_逼近法.py`，对同一目标改变初始关节角，观察解和迭代路径。雅可比矩阵把小幅关节增量映射到局部末端位移，示例用伪逆求增量。初值、步长、停止误差、关节限位都会影响结果。只要程序返回未收敛或剩余误差过大，就记录为失败。
- **核对解。** 把选中的关节角送回正解，计算目标点与实际末端的距离。再看关节限位、和当前姿态的角差以及碰撞情况。指定三维位置只给出三项约束，若任务还要求夹爪朝向，需给出可由该机械臂自由度实现的姿态约束。

### 4. 在示教界面核对坐标

在 `机械臂运动学.zip` 中打开 `forward_kinematics/playground/`，使用仓库锁文件安装依赖后运行 `npm run dev`。先操纵虚拟关节观察末端读数，再输入工作空间内的小幅目标位移，观察逆解后的位置。

- `forwardKinematics.js` 连乘关节固定变换与轴旋转。输入为弧度，输出位置单位为米。
- `inverseKinematics.js` 使用数值微分、阻尼、限位和工作空间裁剪。源码的默认位置容差是 `0.01 m`。对被裁剪的目标，检查程序是否返回了调整后的坐标，别把两者混作一个目标。
- `positionControl.js` 应用求解结果。课程版本的渲染代码还对 Three.js 模型做了旋转、缩放和平移。核对尺寸时用运动学坐标。对照 `10_机械臂_反解.py` 的五关节加独立 TCP 偏移方案时，先定义夹爪模型原点与工具中心点（TCP）各在哪。

**验收。** 用一组非零角度和两组可达目标，分别记录轴向、单位、正解值和逆解回代残差。后续如果仿真与实物相差固定偏移，优先核对基座原点与 TCP。若姿态越远误差越大，检查关节零点、单位和连杆尺寸。

课件对应 `具身智能实现03-运动学正解.pptx` 第 7–15、20–32 页和 `具身智能实战04-运动学逆解.pptx` 第 5–21 页。矩阵、雅可比和逆解的补充参考见 [Modern Robotics 官方教材配套章节](https://modernrobotics.northwestern.edu/nu-gm-book-resource/)。
