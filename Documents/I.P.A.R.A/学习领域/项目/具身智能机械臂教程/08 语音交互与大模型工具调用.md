### 一、先把录音、转录、播报跑通

| 阶段 | `代码/asr和tts.zip` 内的入口 | 预期现象 |
| --- | --- | --- |
| 录音 | `code/audio/01_录音demo代码.py` | 当前目录生成单声道、44.1 kHz 的 `interactive_output.wav` |
| 离线 ASR | `code/audio/02_录音转文本.py` | 脚本自己录制单声道、16 kHz 音频，用同目录 `base.pt` 识别中文，打印转录结果并清理临时 WAV |
| 在线 TTS | `code/audio/03_文本转语音.py` | `edge_tts` 用 `zh-CN-XiaoxiaoNeural` 生成 `test_audio.mp3`，需要网络 |
| 离线 TTS | `code/audio/04_文本转语音_offline.py` | `pyttsx3` 调用操作系统语音引擎朗读，中文效果取决于已安装的 voice |
| 规则聊天 | `code/audio/05_ai_chat.py` 至 `07_ai_chat_v3.py` | 先测文字匹配，再在第 07 个源码脚本里接录音、识别和播报 |

从本地资料解压到单独工作目录，在 `code/audio/` 下打开终端。可以先用 Python 3.10 的独立环境复现录音，按需安装语音包。

```bash
conda create -n arm-voice python=3.10
conda activate arm-voice
python -m pip install pyaudio openai-whisper pyttsx3 edge-tts
ffmpeg -version
python "01_录音demo代码.py"

python "04_文本转语音_offline.py"
```

Linux 上若 PyAudio 编译提示找不到 `portaudio.h`，安装该发行版的 PortAudio 开发包再重试，例如 Debian/Ubuntu 的 `portaudio19-dev`。Windows 侧在系统中为麦克风授权并让终端能够找到可信来源的 FFmpeg。若转录时报 `./base.pt` 不存在，先确认工作目录。Whisper CLI 也支持 `--model base` 形式，并会处理模型的下载和缓存。分别用安静环境与有背景噪声的环境读一次「把黑色方块放进盒子」，记录转录是否保留目标和动作词。 [Whisper 官方安装与 CLI](https://github.com/openai/whisper)

### 三、MCP 消息怎么走

宿主先初始化 MCP 会话，以 `list_tools()` 取得工具名称、描述和输入 Schema，再转换成模型 API 所需的工具声明。模型有可能返回普通答复，也可能返回带 ID 的工具请求。宿主解析 JSON 参数，调用 `call_tool(name, arguments)`，以原 `tool_call_id` 把结果放回对话，再请求最终答复。模型可能给出不存在的名称或错误参数，工具响应和设备反馈是执行结果的依据。 [MCP 架构](https://modelcontextprotocol.io/docs/learn/architecture) · [DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)

课程入口是 `大模型mcp和行为克隆.zip` 内的 `code/上课案例/mcp_server.py` 和 `code/上课案例/01_mcp_deepseek_chat.py`。服务端用旧式 SSE 传输，客户端默认地址 `http://localhost:8000/sse`。同一个服务端注册了加减乘除、文件名搜索、舵机角度和离线语音播报。按源代码默认参数，文件搜索从 Windows 的 `D:\` 开始，舵机工具可打开串口写入目标位置。初次复现使用下节只注册计算和样例目录搜索的服务。若后续要接实机，将端口、零位、方向、逐关节限位、单次最大位移和人工停止纳入独立的驱动侧检查。

对照 [P94 MCP 概念](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=94)、[P95 幻觉](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=95)、[P96 客户端与服务端](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=96)、[P97 工具识别](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=97)、[P98 聊天调用 MCP](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=98)、[P99 文件搜索](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=99)、[P100 实机控制](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=100)、[P101 语音播报](https://www.bilibili.com/video/BV1nz6KBHEc9/?p=101)。

### 四、用 stdio 查工具、算加法、搜索样例

把以下代码保存为 `mcp_lab.py`。客户端启动同一脚本的服务子进程并走 stdio，临时目录仅含两份示例文件。两次请求直接由客户端构造，可以先看清工具事件和参数类型，再跟云对话模型衔接。

```python
import asyncio
import fnmatch
from pathlib import Path
import sys
from tempfile import TemporaryDirectory

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from mcp.server.fastmcp import FastMCP


def serve(sample_dir: Path) -> None:
    server = FastMCP("arm-course-lab")

    @server.tool()
    def add(a: int, b: int) -> int:
        """把两个整数相加。"""
        return a + b

    @server.tool()
    def find_sample(pattern: str) -> list[str]:
        """按名称匹配临时目录里的样例文件。"""
        return sorted(
            path.name
            for path in sample_dir.iterdir()
            if path.is_file() and fnmatch.fnmatchcase(path.name, pattern)
        )

    server.run(transport="stdio")


async def use_tools(sample_dir: Path) -> None:
    params = StdioServerParameters(
        command=sys.executable,
        args=[str(Path(__file__).resolve()), "--serve", str(sample_dir)],
    )
    async with stdio_client(params) as streams:
        async with ClientSession(*streams) as session:
            await session.initialize()
            listed = await session.list_tools()
            print("tools =", sorted(tool.name for tool in listed.tools))
            requests = (("add", {"a": 3, "b": 5}), ("find_sample", {"pattern": "*.txt"}))
            for name, arguments in requests:
                result = await session.call_tool(name, arguments=arguments)
                if result.isError:
                    raise RuntimeError(f"{name}: {result.content}")
                print(f"{name} =", result.structuredContent["result"])


if __name__ == "__main__":
    if len(sys.argv) == 3 and sys.argv[1] == "--serve":
        serve(Path(sys.argv[2]))
    else:
        with TemporaryDirectory() as temp_dir:
            sample_dir = Path(temp_dir)
            (sample_dir / "example.txt").write_text("demo\n", encoding="utf-8")
            (sample_dir / "camera.json").write_text("{}\n", encoding="utf-8")
            asyncio.run(use_tools(sample_dir))
```

```bash
python -m pip install "mcp==1.30.0"
python mcp_lab.py
```

实测使用 MCP Python SDK 1.30.0，标准输出如下。客户端连接不上时，先核对启动命令使用的是装有 `mcp` 的 Python。stdio 服务的标准输出承载协议消息，诊断日志放在标准错误输出。迁移到课程 SSE 时，客户端和服务端的传输和路径应成对核对。 [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk)

```text

add = 8
find_sample = ['example.txt']
```
