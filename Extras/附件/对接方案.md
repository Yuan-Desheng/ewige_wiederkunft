### 1. 现状分析

`KpiSectionRows.vue` 当前所有数据（9 个 KPI 卡片 + 2 个迷你图表 + 趋势预测）都是**硬编码**在 `computed` 中的静态值，按 `activeRange`（24h / 7d / 月）分支返回不同数据。没有调用任何 API。

项目现有的三种数据模式：
- **Pattern A**：`http` 直接调用（auth.ts）— 调用方自行管理 loading/error
- **Pattern B**：`vue-request` 的 `useRequest`（mock.ts）— 响应式 `{ data, loading, error }`
- **Pattern C**：`useForecastData.ts` 纯同步函数 — 确定性伪随机生成

### 2. 对接步骤

**Step 1 — 根据 Swagger 文档定义 TypeScript 类型**

在 `src/pages/forecast/types/` 或直接在 API 文件中定义请求参数和响应类型：

```ts
// 例：src/api/forecast.ts
interface KpiRequest {
  range: '24h' | '7d' | '30d'
  region?: string
}

interface KpiResponse {
  kpiData: KpiItem[]
  forecastMini: { ... }
  chartData: { ... }
}
```

**Step 2 — 创建 API 函数**

在 `src/api/forecast.ts` 中封装接口调用，复用现有 `http` 实例：

```ts
import { http } from '~/composables/http'

export function getKpiData(params: KpiRequest) {
  return http.get<KpiResponse>('/forecast/kpi', { params })
}
```

**Step 3 — 创建 composable 管理数据请求**

在 `src/pages/forecast/composables/useKpiApi.ts` 中用 `vue-request` 包装：

```ts
import { useRequest } from 'vue-request'
import { getKpiData } from '~/api/forecast'

export function useKpiApi(activeRange: Ref<string>) {
  const { data, loading, error, refresh } = useRequest(
    () => getKpiData({ range: activeRange.value }),
    {
      refreshDeps: [activeRange],  // range 变化自动重新请求
      cacheKey: (range) => `kpi-${range}`,
    },
  )
  return { data, loading, error, refresh }
}
```

**Step 4 — 改造 `KpiSectionRows.vue`**

用 API 返回数据替换硬编码的 `computed`：

```diff
- const kpiData = computed(() => { ... hardcoded ... })
+ const { data, loading } = useKpiApi(toRef(props, 'activeRange'))
+ const kpiData = computed(() => data.value?.kpiData ?? [])
+ const forecastMini = computed(() => data.value?.forecastMini)
```

加入 loading 骨架屏和 error 处理。
